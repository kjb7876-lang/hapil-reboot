# 합일 — 코스믹 가면 루시퍼 v7

정원 → 거미동굴 → 늪 → 발록 → 병원·주사실 → 중독의 도시 → 웃는 가면 → 코스믹 가면 루시퍼. 13개 일반 구간, 보스 5명, 15개 패턴과 J의 인장으로 물러나는 결말을 구현했습니다. 보스 연습 메뉴에서 각 전투를 바로 선택할 수 있습니다.

PC: 방향키/WASD, Shift 정밀 이동. 모바일: 화면 또는 하단 패드를 상대 드래그. 공격·조준·스킬은 자동이며 설정에서 스킬 순환을 끌 수 있습니다. Escape/Space 일시정지, 등장 연출 Enter/버튼 건너뛰기.

## 변경

- 기존 Drive 원화로 루시퍼·웃는 가면·병원 환각·약병 환각·근위천사·부정의 잔영의 24자세 추가. 해시, 원본 사각형, RGBA 픽셀과 실 부착점 검사.
- 새 보스 자세 전환 보간, 천구·깃털·교차 광선·가면 균열, 패턴 이름 연출. 병원 회랑과 천구는 코드로 그린 배경입니다.
- 모든 현재 전투 몹과 보스에 무해한 가는 실. 레이저는 예고 → 고정된 실제 광선 → 무해한 잔광을 유지합니다.
- 추가 원화는 해당 구간 진입 시 로딩하며 전투 시계를 정지합니다. 다른 확장 구간의 이미지 참조는 해제합니다. 실제 브라우저 디코더/GPU 회수량은 미측정입니다.
- 이전 v3 및 v6.1 저장 복원 호환. 새 캠페인 체크포인트 revision 2, 기존 저장소 이름 유지.

## 실행과 검증

`index.html`, `styles.css`, `src/`, `media/`를 동일한 루트에 유지하세요. GitHub Pages는 main / root를 사용합니다. 단일 HTML도 별도 제공합니다.

검사: `node --test tests/*.test.cjs`
CPU 화면 검사: `node tools/cpu-v7.cjs` (`@napi-rs/canvas` 필요)
패키징: `python tools/build.py`

CPU/논리 DOM 검사는 실제 브라우저, GPU, 음향 재생, 실제 IndexedDB, 모바일 터치 실기 검증을 대체하지 않습니다. CPU 환경에는 한글 글꼴이 없어 한글 자형의 픽셀 검증은 제외했으며 텍스트 내용은 논리 DOM 검사로 확인했습니다. 원화는 보스별 4자세이며 새로 제작한 연속 애니메이션 프레임은 아닙니다. 원화의 흰 날개를 검은 날개로 바꾸는 새 이미지 자산은 제작하지 않았습니다. 가면과 균열은 코드 연출입니다.

`docs/DCOS-LUCIFER-PROMPTS-KO.md` 등 이전 제작 요청서는 향후 고품질 연속 프레임 제작용이며, v7 구현 상태는 이 README와 `qa/revision7-summary.json`을 따릅니다. 이전 qa/revision* 자료는 당시 버전의 역사적 검사입니다.
