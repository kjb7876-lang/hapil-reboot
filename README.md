# 합일 — 코스믹 가면 루시퍼 v8

정원에서 코스믹 가면 루시퍼까지 13구간·5보스·15패턴을 진행하는 세로 탄막 게임입니다. PC는 방향키/WASD와 Shift 정밀 이동, 모바일은 상대 드래그를 사용합니다. 자동 공격·조준·스킬 순환, 보스별 연습, 저장 복원이 있습니다.

이번 버전은 사용자가 Drive에 전달한 보스 5종의 아래방향 핵심 자세 20개를 적용합니다. 자세별 상체 중심을 맞추고 준비 → 내려치기 → 후속 → 회복을 기존 전투 시계에 연결했습니다. 원본은 4자세 후보이며, 짧은 자세 겹침을 사용해 연결했습니다. 새 연속 애니메이션 프레임을 생성한 것은 아닙니다.

| 보스 | 주색·보조색 | 기존 Drive FX 재사용 |
| --- | --- | --- |
| 보라검천사 | 보라·은청 | 거미줄 봉인·은빛 검격 |
| 뿔악마 | 청록·연금 | 늪 파문·갈대 투사체 |
| 발록 | 주홍·금 | 불씨·황금 검격 |
| 웃는 가면 | 상아금·홍자주 | 기억 해방·황금 검격 |
| 루시퍼 | 코스믹 보라·금·홍자주 | 붕괴 소용돌이·은빛 검격·기억 해방 |

고해상도 원화를 매 탄환마다 합성하던 경로를 작은 불투명 탄체 캐시로 바꿨습니다. 원·캡슐의 실제 판정과 예고 → 실제 광선 → 무해한 잔광을 유지하며, 모바일에도 보스별 자산을 표시합니다. 캐시는 최대 96개이고 구간 전환 시 해제합니다. 시전 FX는 보스당 단발 1개, 모바일 최대 60px입니다. 기억·시간 지연·반격·자아 각성에는 기존 플레이어 자산과 짧은 보조 연출을 연결했습니다.

모바일 기본 30FPS·DPR 1과 구간별 이미지 로딩을 유지합니다. PC도 해당 구간 자산만 불러옵니다. 동시 이미지 요청은 최대 2개이며 중복·시간 초과·취소된 요청을 정리합니다. 일시정지/결과 화면은 변경될 때만 다시 그립니다. 같은 텍스트와 같은 캔버스 크기의 반복 갱신도 생략합니다.

## 실행

`index.html`, `styles.css`, `src/`, `media/`를 같은 루트에 두세요. GitHub Pages는 main/root입니다. 단일 HTML과 업로드 ZIP, 20MB 미만의 독립 소스 ZIP도 별도로 제공합니다. 소스 ZIP은 모두 같은 빈 폴더에 압축 해제합니다.

검사: `node --test tests/*.test.cjs`
CPU 검토: `node tools/cpu-v8.cjs` (`@napi-rs/canvas`, Pillow 필요)
패키징: `python tools/build.py` 후 `python tools/split-source.py`

검사 결과는 `qa/revision8-*`, 원본·파생 이력은 `docs/reused-boss-motion-v8.json`, `docs/reused-drive-fx-v8.json`에 있습니다. 이전 revision 보고서는 당시 버전의 기록입니다. 새 이미지나 음원은 생성하지 않았습니다. FX 축소본은 기존 원본 셀의 등비 파생입니다. 원본 보스 아틀라스 바이트와 20개 프레임 픽셀을 대조했습니다.

실제 브라우저/GPU/휴대폰 성능, 음향 재생, 한글 글꼴의 픽셀 형태는 미검증입니다. CPU 캔버스 검사는 이를 대신하지 않습니다. 이전 저장 호환과 현재 전투 진행은 자동 회귀 검사로 확인합니다. 기존 hapil1과 이전 버전은 보존합니다.
