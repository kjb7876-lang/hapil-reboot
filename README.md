# 합일 — 전투 가독성 개선 v20

탄환의 윤곽을 유지하면서 실제 게임 크기·회전·부분 픽셀 위치의 가독성을 다시 검사한 개선판입니다. 본편은 아래 v19의 프롤로그~제8부 사몽 각성·몽세수호자 결말 범위를 유지합니다. 전투 판정·탄속·진행·저장·서사는 바꾸지 않았습니다.

- 중앙을 계속 덮던 안내판을 없앴습니다. 패턴명·남은 시간·실제 레이저의 예고/활성/잔광 상태는 상단, 회피 설명은 전투장 아래 조작 패드에서 읽습니다.
- 중복된 패턴 시작 문구와 폭 넘침을 고쳤습니다. 탄환이나 광선이 나타나면 시작 문구를 즉시 감춰 공격을 읽을 공간을 남깁니다. 예고선의 어두운 밑선도 실제 확정 경로 안에만 표시합니다.
- 여섯 분신처럼 같은 순간에 다른 위치에서 발사하는 공격 연출을 각각 표시합니다. 실제 발사 위치를 우선하며 고품질8개·절전4개 상한을 유지합니다.
- 실제 탄환 크기에서 흐려지던 중심과 곡검의 중심, 한리안의 길쭉한 탄체 방향을 보정했습니다. 원본 알파를 따르는 작은 경계는 캐시에만 만들고 일반 탄체는 실제 프레임에 한 번 그립니다. 둥근 탄체의 고정 문양과 길쭉한 탄체의 물리 방향을 구분합니다.
- 상단 정보와 보조색 객체를 재사용해 반복 배치·객체 생성을 줄였습니다. 새 원화를 유료로 생성하거나 다른 보스 이미지로 대체하지 않았습니다.

실제 표시 크기와 부분 좌표 검사·전체 회귀·CPU·브라우저·실제 기기의 범위를 구분합니다. 자세한 검수 결과는 `docs/V20-*` 문서에 기록합니다. CPU와 짧은 브라우저 입력 검사는 휴대폰의 지속 FPS 인증이 아닙니다.

## v19 스토리모드 적용 기록


세로 탄막 스토리모드의 핵심 경로를 프롤로그에서 제8부 사몽 각성과 몽세수호자 결말까지 연결한 개선판입니다. 새 본편 revision5는 **35전투 구성·105페이즈·208안전 경계**입니다. 여섯 통제 장면, 수문장 집단, 회로 절단·보호 임무도 구성에 포함하므로 35명의 서로 다른 정본 보스라는 뜻이 아닙니다. 비전투 장면과 제7부 인간의 기억은 순서가 있는 서사 전환으로 요약했습니다. 모든 원문 장면을 별도 맵·개별 보스로 만든 완전 재현판이라고 주장하지 않습니다. 사몽 후속편·역행·네오서울 확장·미카엘라 엔딩은 포함하지 않습니다.

탄환은 원·캡슐로 자산의 윤곽을 잘라내던 처리를 제거하고, 해당 보스의 실제 검·깃·베개·거울 파편·심장·동전·불꽃·역십자 등의 외곽과 명암을 유지합니다. 작은 장식 외곽은 실제 피격 영역보다 최대 약4px 넓을 수 있으며, 전투 판정 자체는 기존 엔진의 반경·캡슐을 유지합니다. 공격 본체는 실제 원화 픽셀만 사용하며 도형이나 다른 보스 이미지로 대체하지 않습니다. 레이저는 예고 경로와 실제 피해 구간을 유지합니다. 보스별 특수 패턴 이름과 피하는 방법을 전투 중에도 표시합니다.

시작 화면에서 **보스 선택 → 특수 패턴 ↗**을 누르면 세 번째 패턴을 바로 연습할 수 있습니다. **보스 연습 ↗**은 첫 패턴부터 시작합니다. 두 연습 모두 본편 체크포인트·백업·클리어 기록을 덮어쓰지 않습니다. 기존 revision1~4 이어하기와 재시도는 원래 경로를 유지합니다. 새 전체 경로는 **공간체험 여정 시작**에서 시작하며, 기존 저장을 지울 필요는 없습니다.

후반부에는 읽기 전용 `hapil1`과 Drive에서 확인한79개 원화·맵·고유 FX·환도/윤서하 본체·사몽 각성·일반 적 자산을 사용합니다. 정적1자세·2상태·4핵심 자세가 혼재하며, 완전한 연속 애니메이션이라고 부르지 않습니다. 보호할 주민·기억·아르벨리아와 공격할 명령선은 구분하고, 한리안·백이온은 별개의 두 시전자로 표시합니다. 타락천사에게 패배하는 사건과 성 함락, 교주 부활 뒤 살아 있는 상태에서 사몽에 이르는 순서를 보존합니다. 최종장에서는 코어를 남기고 강제 명령과 사이비 회로만 분리합니다.

이미지는 현재 구간만 최대2개 동시 로딩하며, 필수 공격 이미지의 누락·규격 오류는 전투 전에 차단합니다. 탄환 캐시4MiB·스킬2MiB·단일 배경 캐시 상한을 유지합니다. 실제 휴대폰의 지속 FPS와 GPU 성능은 별도 검증하지 못했으며 모바일 무렉을 보장하지 않습니다.

실행: 루트 `index.html` 또는 GitHub Pages(main/root). 자동 검사: `npm test`. CPU·고정 면역 fixture·일반 체력 자동 진행·실제 브라우저 검증은 서로 구분합니다. 정본 및 구현 범위는 `docs/V19-CANON-IMPLEMENTATION-REVIEW-20261030.md`, 자산 출처·해시는 `docs/V19-STORY-ASSET-PROVENANCE-20261030.json`과 `docs/V19-INDEPENDENT-SOURCE-VERIFY-20261030.json`을 참조하세요. 테스트 기록은 검증 당시 코드 해시에만 적용됩니다. 아래는 이전 버전의 기록입니다.

## v18 적용 기록

세로 탄막 게임의 플레이 테스트용 개선판입니다. 기존 정원·루시퍼·7대죄 구간에 최신 정본의 제3부 `u201→u202→u204→u205→u206→u203`을 연결했습니다. 새 본편은 18개 전투 구성·54페이즈이며, 제3부 여섯 구성은 하나의 통제 체계가 있는 여섯 장소입니다. 기억을 파괴하지 않고 반복 명령의 연결을 끊어 첫째의 의지가 환도라는 칼로 이어지는 데까지 구현했습니다. 제4~8부 전체 스토리는 아직 연결하지 않았으며 제8부 교주 연습은 별도입니다.

새 경로는 **공간체험 여정 시작**, 새 전투는 **연습할 보스 → 제3부 항목 → 보스 연습**으로 실행합니다. 기존 revision1~3 이어하기/재시도는 원래 경로를 유지하고 강제로 새 경로로 옮기지 않습니다. 저장을 지울 필요는 없습니다. PC 방향키/WASD와 Shift 정밀 이동, 모바일 상대 드래그를 유지했습니다.

Drive의 장면별 자세와 읽기 전용 `hapil1` 원화를 사용해 제3부 본체·맵·드론·전용 탄환·레이저·시전 표시를 추가했습니다. 실제 발사와 레이저 활성 시점에 핵심 자세를 연결했고 23개 자세의 몸통 앵커를 픽셀로 검수했습니다. 이 정적 핵심 자세들을 완전한 연속 애니메이션이라고 부르지 않습니다. 필수 이미지가 누락되면 다른 보스나 도형으로 대체하지 않고 전투 전에 오류를 표시합니다. 구간별 이미지 로딩은 동시 2개, 탄환 스탬프 4MiB·스킬 2MiB·제3부 배경 1,036,800바이트의 캐시 상한을 둡니다.

정본·자산 출처와 해시: `docs/LATEST-CANON-INTEGRATION-20261030.md`, `docs/CHAPTER3-RUNTIME-ASSETS-V18-20261030.json`. 검증 종류와 한계: `docs/V18-INDEPENDENT-QA-20261030.md`, `docs/V18-BROWSER-QA-20261030.md`, `docs/CHAPTER3-VISUAL-CPU-20261030.json`. 실제 휴대폰과 GPU 성능은 아직 검증하지 못했습니다. CPU/짧은 브라우저 검사로 모바일 무렉을 보장하지 않습니다.

실행은 저장소 루트 `index.html`이며 GitHub Pages는 main/root입니다. 검사: `npm test`. CPU 실제 이미지 렌더: `node tools/measure-chapter3-v18.cjs` (`@napi-rs/canvas` 필요). 아래 v8 패키징 설명은 과거 버전 기록으로 현재 통합판의 별도 단일 HTML 배포를 뜻하지 않습니다.

## v8 적용 기록

정원에서 코스믹 가면 루시퍼까지 13구간·5보스·15패턴을 진행하는 세로 탄막 게임입니다. PC는 방향키/WASD와 Shift 정밀 이동, 모바일은 상대 드래그를 사용합니다. 자동 공격·조준·스킬 순환, 보스별 연습, 저장 복원이 있습니다.

이번 버전은 사용자가 Drive에 전달한 보스 5종의 아래방향 핵심 자세 20개를 적용합니다. 자세별 상체 중심을 맞추고 준비 → 내려치기 → 후속 → 회복을 기존 전투 시계에 연결했습니다. 원본은 4자세 후보이며, 짧은 자세 겹침을 사용해 연결했습니다. 새 연속 애니메이션 프레임을 생성한 것은 아닙니다.

| 보스 | 주색·보조색 | 기존 Drive FX 재사용 |
| --- | --- | --- |
| 보라검천사 | 보라·은청 | 거미줄 봉인·은빛 검격 |
| 뿔악마 | 청록·연금 | 늪 파문·갈대 투사체 |
| 발록 | 주홍·금 | 불씨·황금 검격 |

고해상도 원화를 매 탄환마다 합성하던 경로를 작은 불투명 탄체 캐시로 바꿨습니다. 원·캡슐의 실제 판정과 예고 → 실제 광선 → 무해한 잔광을 유지하며, 모바일에도 보스별 자산을 표시합니다. 캐시는 최대 96개이고 구간 전환 시 해제합니다. 시전 FX는 보스당 단발 1개, 모바일 최대 60px입니다. 기억·시간 지연·반격·자아 각성에는 기존 플레이어 자산과 짧은 보조 연출을 연결했습니다.

모바일 기본 30FPS·DPR 1과 구간별 이미지 로딩을 유지합니다. PC도 해당 구간 자산만 불러옵니다. 동시 이미지 요청은 최대 2개이며 중복·시간 초과·취소된 요청을 정리합니다. 일시정지/결과 화면은 변경될 때만 다시 그립니다. 같은 텍스트와 같은 캔버스 크기의 반복 갱신도 생략합니다.

## 실행

`index.html`, `styles.css`, `src/`, `media/`를 같은 루트에 두세요. GitHub Pages는 main/root입니다. 단일 HTML과 업로드 ZIP, 20MB 미만의 독립 소스 ZIP도 별도로 제공합니다. 소스 ZIP은 모두 같은 빈 폴더에 압축 해제합니다.

검사: `node --test tests/*.test.cjs`
CPU 검토: `node tools/cpu-v8.cjs` (`@napi-rs/canvas`, Pillow 필요)
패키징: `python tools/build.py` 후 `python tools/split-source.py`

실제 브라우저/GPU/휴대폰 성능, 음향 재생, 한글 글꼴의 픽셀 형태는 미검증입니다. CPU 캔버스 검사는 이를 대신하지 않습니다. 이전 저장 호환과 현재 전투 진행은 자동 회귀 검사로 확인합니다. 기존 hapil1과 이전 버전은 보존합니다.
