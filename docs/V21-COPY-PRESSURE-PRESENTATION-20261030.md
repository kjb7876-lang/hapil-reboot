# V21 환영·분신과 압박 공격의 이미지 검수

분신은 현재 적의 자기 원본 이미지와 기존 자세를 그대로 사용하는 투영이다. 인물이나 새로운 프레임을 만들지 않았다. 상시 장식 원·실루엣 대체·다른 보스 이미지도 추가하지 않았다. 실제 생성·위치·발사·만료는 코어가 소유한다.

`actors.drawCombatCopy`는 원본의 등록된 피벗과 자세를 재사용한다. 최대2개를 기존 보스 폭230보다 작은155로 그린다. 본체와 다른 투명도로 구분하며 실제 발사 뒤6틱 동안 원본의 공격 자세가 더 선명하게 보인다. 생성12틱 동안만 등장 투명도를 보간하고, 사라지기 전에 피해 공격을 숨기는 효과는 없다. 수명은 `born <= tick < expireAt`로 엄격히 제한한다. 레이저와 탄환은 분신보다 위에 그려진다.

한리안·백이온은 고유 발사자 ID와 원본 인물 ID를 분리한다. 분신 본체·탄환·레이저·시전 효과 모두 `modelActorId`로 원본 인물을 고른다. 둘을 합쳐 그리거나 보호 대상·주변 인물을 함께 복제하지 않는다. 모델을 고를 수 없거나 원본이 없으면 도형으로 대체하지 않고 누락으로 기록한다.

## 반복 검수에서 고친 문제

첫 검수의66% 압박은 모든 보스에게 같은 세로 벽 세 개로 보였다. 실제 픽셀을 확인한 뒤 이를 수정 요청했고, 최종 코어는 세로·가로·격자(#) 세 배치를 사용한다. 최종42장면은 세 배치를 모두 포함한다. 원본 질감과 색은 보스 자기 자산을 유지한다.

금빛 가로·격자 광선은 완전 불투명일 때 탄환 중심과 경쟁했다. 동일 실제 코어 상태와 원본 이미지로 투명도1/.72/.6을 별도 CPU 화면에서 대조하고, 담당자와 root가 직접 확인했다. 최종본은 압박 광선만 활성 투명도.72로 낮췄다. 넓은 공격 경계와 원본 질감은 뚜렷하고 탄환 중심도 읽힌다. 일반 레이저는1, 피해 종료 뒤 잔광은 기존 fade 시계를 유지한다. 충돌 넓이·발사 예고·피해 시작·종료 시점은 수정하지 않았다.
