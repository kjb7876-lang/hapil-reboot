한리안·백이온은 서로 다른 원본 사람 이미지와 서로 다른 준비/실제 발사 시계를 쓴다. 실제 사격은 각자의 `sourceActorId`로 역십자/방벽 자료와 색을 고른다. 원문의 두 기술을 각 인물에게 고정한 대사로 창작하지 않는다. 이 자료 연결은 기존 원본 게임의 공격 자산에 따른 시각적 게임 각색이다. 실제 탄환과 광선은 항상 몸체 위에 그리며, 사람이 안 보인다는 이유로 피해 표시를 몸체 뒤로 감추지 않는다. 두 사람 이름을 발밑에 짧게 적고, 등장 연출에서는 실제 상대 위치를 유지한 채 크기를1.15배로 제한한다.

고블린의 작은 기본 탄환은 자체 몸체에 있는 실제 피리 끝부분, 세이렌의 작은 기본 탄환은 자체 공격 원화에 있는 실제 시간 무기의 끝부분을 사용한다. 원래 투명한 오브젝트를 고르며, 넓은 주문 필드의 불투명 배경을 작은 사각 카드로 잘라 쓰지 않는다. 큰 원본 주문 필드는 소유자의 큰 시전 효과로 유지한다. 임의 원/캡슐 마스크나 배경 채색을 더하지 않는다.

## 자세와 플레이어

기존 정적 원화를 실제 `releaseTick` 직후12틱 동안 발사 자세로 선택한다. 이름이 transition인 파일을 공격 회복 동작이라고 부르지 않는다. 그러한 네 번째 정적 원화는 실제 페이즈 전환에만 선택한다. 기사의 MoveSide는 이동 상태용이며 분신의 회복 상태는 기본 자세다. 한리안/백이온은 대기와 실제 공격 두 정적 상태만 있고, 일부 구조물/적은 한 장이다. 이들에 새 아래 방향 연속 프레임을 생성한 것은 아니다.

신규 메타데이터와 기존 교주를 포함한46개 고유 원본 앵커 지점을 실제 RGBA로 읽었으며 알파는244~255였다. 이는 수동 표시 앵커의 가시성 검사이지 물리 피벗이 원본 제작자에게 인증됐다는 뜻은 아니다. 원본 RGBA의 투명 픽셀에 남은 RGB는 불투명 합성으로 보이지 않는지 확인했다. 원시 투명 미리보기의 숨은 RGB만 보고 원본이 손상됐다고 판정하지 않았다.

제5부는 윤서하, 나머지 신규 구간은 환도의 실제 원본 몸체를 사용한다. 사몽 각성 원화는 원본 RC91에서 환도의 사몽 모드로 확인된 파일이며, 엔진의 실제 `samongAwakened` 상태일 때만 바꾼다. 같은 인물이 움직이는 정적 몸체 표시이지 새 보행 애니메이션이 아니다.

환도와 윤서하의 일반 사격 및 기억 스킬은 각자의 실제 검격 자료를 사용한다. 구형 건너의 바람 화살을 새로운 인물에게 강제로 재사용하지 않는다. 원본 비율과 알파를 보존한96×64 스탬프 하나(24,576바이트)를 쓰며 구간이 바뀌면 교체하고 renderer 해제 시 비운다. 공격·조준·판정·이동은 엔진 값을 그대로 사용한다.

## 특수 패턴의 가독성 및 성능 범위

모든 보스의 특수 페이즈 이름과 회피 힌트를 1.45초 뒤에도 y203~250의 작은 패널에 유지한다. 실제 위협은 나중에 그려 패널 아래에 숨기지 않는다. 보스별 자체 시전/발사 자료는 실제 확정 발사 이벤트에만 연결한다. 원화 네 장으로 완전한 연속 애니메이션을 만들었다고 주장하지 않는다.

맵은 자체 전체 원화와 그 원화의 바닥 샘플을 한 번만 합성한다. 구간별360×720 배경 캐시는1,036,800바이트다. 탄환4MiB/96항목, 스킬2MiB/24항목, 플레이어 검격24KiB의 상한을 유지한다. 세부 형상 개선 때문에 일반 탄환마다 고해상도 이미지를 다시 합성하지 않는다.

`tests/story-visuals-v19.test.cjs`는 실제 디코딩한 이미지로 네 계약 검사를 한다. 17구간의 필수 이미지 실패 처리와 보호 대상 분리, 두 사람의 독립 발사와 등장 위치, 여섯 분신과 별도 논리 표식, 자체 플레이어/사격과 실제 사몽 상태를 확인한다. 면역/위치 고정 관찰은 자연 진행과 구분한다.

별도 CPU Canvas 측정의 최종 파일은 `V19-STORY-VISUAL-CPU-20261030.json`이다. 17구간×2난도×실제페이즈3 peak/release×2품질의136장면을4회 예열 후20회씩 측정한다(2,720회 측정 렌더). 1,800틱씩 실제 엔진을 관찰하지만 플레이어 공격/스킬을 끄고 명시적 피해 면역을 주므로 자연 진행 검사가 아니다. 소스가 측정 중 바뀌면 결과 파일을 성공으로 내보내지 않는다.

이 CPU 환경에는 한국어 글꼴이 설치돼 있지 않아 한국어 글자의 픽셀 모양/줄바꿈 인증은 하지 않는다. 실제 Chrome의 특수 패턴 문구 검수는 루트 담당 브라우저 기록을 따른다. CPU 이미지의 빈 글자 영역을 실제 브라우저의 빈 UI라고 해석하지 않는다. CPU 렌더 시간은 GPU 완료 시간, 실제 휴대폰 성능, 지속 FPS나 자연 진행 난이도를 증명하지 않는다.
