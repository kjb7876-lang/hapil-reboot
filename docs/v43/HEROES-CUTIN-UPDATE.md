# 윤서하·본보스 컷신·대형탄 파괴 업데이트

## 플레이

처음부터 또는 스테이지 선택으로 시작하면 기억사수와 윤서하 중 하나를 고릅니다. 선택 확정 전에는 전투가 시작되지 않습니다. 이어하기와 재도전은 해당 여정의 영웅을 유지하며, 예전 저장은 기억사수로 복원합니다.

윤서하는 서사 정본의 카이로스 아카데미움·시간공학·검술 설정을 바탕으로 소녀 시절을 새로 시각화했습니다. 원전 문장은 수정하지 않았습니다. 새 외형과 기술명은 아케이드 각색입니다. 기본 시간검은 분산, 저속 이동에서는 집중 사격하며 기존 영웅과 동일한 화력·7단계 성장·목숨·필살 규칙을 사용합니다. 헬에는 자동회피와 자동폭탄을 추가하지 않았습니다.

## 본보스 등장 순서

중간보스 격파 → 다음 본보스의 등장 구간 진입 → 1.8초 컷인 → 정본 발췌 → 본보스 생성·등장 → 전투. 거미 중간보스에는 보라검천사 컷인이 재생되지 않습니다. 화면은 다가올 본보스의 이름과 초상을 사용하고, 컷신 동안 전투 틱·체력·폭탄은 진행하지 않습니다. Esc로 연출도 멈추며 건너뛰기가 가능합니다. 기존 잘못된 시점의 읽음 기록과 새 본보스 기록은 구분했습니다.

## 대형탄 파괴

첨부한 대형 기물탄의 몸체를 기준으로, 모바일 축소 전 긴 변 56 이상인 탄 중 결정적으로 3개에 1개만 사격 파괴 대상으로 지정합니다. 발광·생성 팽창 크기는 기준에서 제외합니다. 현재 큰 톱니·기계 핵이 해당하고 작은 구슬과 버블은 해당하지 않습니다. 대상에는 금빛 균열 표시가 있습니다.

대형탄 하나를 부수면 그 탄만 사라지고 작은 잔탄 3개가 플레이어 반대 방향으로 펼쳐집니다. 잔탄은 0.6초 동안 옅게 보이며 충돌하지 않고 이후 정상 탄이 됩니다. 잔탄은 다시 파괴·분열하지 않습니다. 탄 수가 한계에 달하면 배열 넘침을 막기 위해 확보된 칸만 사용합니다. 폭탄·피격·전환 시 기존 탄 정리는 잔탄 연쇄를 만들지 않습니다.

## 규칙 안내

게임의 탄막 기본 규칙에 영웅 선택, 대형탄 균열과 잔탄, 아래에서 올라오는 적 예고·먹 그림 장애물·낙하 블록·솟은 지형·바닥 레이저를 설명했습니다. 문양 레이저의 형태와 점멸 회피 방식은 유지합니다.

## 검증 범위

영웅별 7단계 공격·필살 수치와 헬 방어 규칙, 크기별 파괴 조건과 잔탄 수명·용량 한계, 56개 스테이지 본보스 컷신 시점, 오디오 중지/재개, 영웅 저장 복원은 자동검사 대상으로 추가했습니다. PC와 모바일 세로 2종·가로 1종의 실제 Chromium 검사에서 영웅 선택·컷인·일시정지·멀티터치 저속/폭탄과 화면 배치를 확인합니다. 이러한 검사는 모든 위치·입력 조합의 무피격 클리어를 수학적으로 보장하지 않습니다.
