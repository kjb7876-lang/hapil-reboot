# 서사 정본과 세로판 장면 대응

사용자가 2026-11-17에 첨부한 `스토리월드_현재_스토리모드_서사_20261117(1).txt`를 이번 서사 기준으로 삼는다. [canonical-story.txt](canonical-story.txt)는 첨부 원문을 바이트 그대로 복사한 파일이다. 원문 내부의 공개판 출처·개정 설명도 고치지 않았다.

`src/arcade-story-v43.js`의 `SOURCE.sha256`이 원문 사본을 식별한다. 56개 전투 스테이지는 정본의 같은 제목 구역과 대응한다. 게임 제목 `무너진성`만 원문의 `무너진 성`에 대응한다. 기존 저장 진행 번호와 전투 스테이지 순서는 바꾸지 않는다.

## 짧은 전투 연출의 원칙

- 모든 장면은 정본의 회고 화자를 표시한 **기억 발췌**다. 서술문을 보스가 한 직접 대사로 바꾸지 않는다. 원문에 없는 주고받는 대화를 정본인 것처럼 추가하지 않는다.
- 각 전투 입장 장면은 해당 구역 앞부분에서 고른 완결 문장 2개다. 문구는 공백 정리 외에 바꾸지 않으며 한 문장은 80자 이하로 제한한다.
- 보스 패배·최종 각성·엔딩 문장을 전투 입장 때 미리 보여주지 않는다. 구역 시작 시 이미 벌어진 사건은 해당 구역 원문 흐름대로 남긴다.
- `durationMs`는 6초의 연출 예산이다. 앱은 문장 길이에 맞춰 표시 시간을 늘리거나 수동 넘기기를 제공할 수 있다. 짧은 발췌가 전체 정본을 대체한다고 주장하지 않는다.
- 상세 서사와 화자 전환의 최종 근거는 원문 파일이다. 예를 들어 환도 영웅은 첫째 아이 자체로 바뀐 인물이 아니라, 아이의 의지가 담긴 칼과 의목사 B의 몸·기억이 함께 움직이는 전투 자아다.

`tests/arcade-v43-canonical-story.test.cjs`는 원문 해시, 56개 대응, 각 문장의 해당 원문 포함 여부, 화자, 모바일 길이, 6개 연결 장면 순서와 브라우저 로드를 검사한다.
