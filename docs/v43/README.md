# v43 — 원큐 56스테이지 여정

세로 총집본(`arcade.html`)을 9스테이지에서 **원작 장면당 1스테이지, 56스테이지**로 바꿨다. 인계서의 "55"는 오기였다. 원작 62장면 중 쉼터 6곳을 뺀 플레이 장면이 56개다.

## 1. 한눈에

| 항목 | v42 | v43 |
|---|---|---|
| 스테이지 | 9 | 56 (보스 스테이지 26, 길목 스테이지 30) |
| 명목 플레이 시간(무적 봇 기준) | 약 35분 | 약 3시간 7분 (11,196초) |
| 이름 붙은 패턴 | 37 | 198 (기본 난이도 화면 탄 최고치 중앙값 315발) |
| 배경 | 9 | 56 (스테이지마다 다름) + 색조 56 + 날씨 16종 |
| 잡몹 종류 | 15 | 47 |
| 인물(보스·길목지기) | 15 | 55 |
| 저장 | 없음 | 스테이지별 저장, 이어하기, 스테이지 선택·잠금, 별 168개, 기념물 56개 |
| 첫 화면 | 스토리판 + 총집본 | 원큐 여정 하나 (옛 스토리판은 `index.html?story`로 보관) |

부별 길이: 1부 12개 38분, 2부 10개 34분, 3부 6개 19분, 4부 5개 19분, 5부 10개 33분, 6부 3개 11분, 7부 4개 13분, 8부 6개 20분.

## 2. 바꾼 것

- **엔진** `src/arcade-v43.js`: 스테이지를 부별 파일(`src/arcade-parts-v43/p1~p8.js`)에서 읽어 조립한다. 스테이지마다 결과(시간·피격·폭탄·별)를 내고, 어느 스테이지에서든 시작할 수 있다. 저장 규칙은 화면과 분리된 `Progress` 모듈이다.
- **스테이지 구조**: 길목 스테이지는 잡몹 구간 여럿 → 길목지기, 보스 스테이지는 잡몹 → 중간 보스 → 잡몹 → 보스.
- **보스 무기 패턴**: 보스와 길목지기마다 원작의 무기·도구를 탄으로 그리는 이름 붙은 패턴을 넣었다(예: 발록의 검, 식칼과 프라이팬, 펜타닐, 노이론 케이블, 시곗바늘). 밀도는 속도가 아니라 탄 수로 올렸다.
- **화면** `src/arcade-app-v43.js`: 이어하기, 스테이지 선택과 잠금, 기념물 모음, 보스 체험, 날씨 16종, 움직이는 그림(걷기 4칸). 그림은 스테이지 단위로 읽고 지난 스테이지 것은 버린다.
- **그림 묶음** `media/arcade-v43/`(248장, 6.7MB): `tools/build-arcade-art-v43.py`가 배정표 `tools/arcade-art-v43/*.json`에서 만든다.
- **삭제**: 9스테이지판 `src/arcade-v38.js`, `src/arcade-app-v38.js`, `tests/arcade-v41·v42.test.cjs`, `media/arcade-v41/`, `tools/build-arcade-art-v41.py` (사용자 결정 2026-11-13).

## 3. 안 바꾼 것

- 서사 내용, 스테이지 이름(원작 장면 제목 그대로), 글은 스테이지 이름 한 줄과 패턴 이름 한 줄뿐.
- 옛 스토리판 파일(`core.js` 등)과 그 테스트.
- 조작 키 수, 탄 색 6가지, 탄 상한(1400 / 휴대폰 820), 소리 크기 순서.
- 십자가는 똑바로 선 기물로만 나온다. 원작의 "황금 역십자가"는 이름만 남기고 탄 무늬는 육망성으로 그렸다.
- 무한·협동·777·패시브 강화·사몽/EGO 각성은 넣지 않았다(다음 단계 후보).

## 10. 하트 아이템·지역별 몹·동작 (2026-11-13 추가)

- **아이템**: 점수 아이템은 분홍 하트, 게이지 아이템은 금빛 하트(뛰는 박동). 드라이브 하트 그림(PJ-03)은 연결 장애로 못 받아 지금은 직접 그린 하트다. `items.heart`를 배정표에 넣으면 그 그림으로 바뀐다.
- **지역별 몹**: m0 지역표(`docs/v43/m0-mobs.json`)대로 장면 54곳에 m0 몹 121종을 입혔다(`src/arcade-skins-v43.js`, 시뮬은 그대로고 그림만 바뀐다). 조형물(참나무)을 몹으로 쓰던 것은 뺐다. m0에 몹 그림이 없는 33·35 장면은 기존 그림 그대로다. 시간탑(38·40~46)과 기억계(27·29)는 그 장면 고유 몹 그림이 모자라 같은 지역 묶음의 몹을 빌려 3종까지 채웠다(`borrowed`).
- **동작**: 몹은 이동 4칸(11종은 2칸) + 공격(75종), 쏜 직후 공격 동작, 가는 방향으로 좌우를 뒤집는다. 드라이브 정면 걷기가 있는 26종은 정면 걷기가 기본이고 m0 이동이 옆 걷기다. 보스 22명은 탄을 뿌리는 순간 m0 공격 자세 4칸(준비·내려치기·끝맺음·되돌아옴)을 보인다.
- **도구**: `tools/import-m0-mobs-v43.py`, `tools/import-m0-bosses-v43.py`, `tools/assign-m0-mobs-v43.py`. 그림 묶음은 493장 15MB(스테이지 단위로만 받는다). 빌더는 바뀐 것만 다시 만든다(`FORCE=1`이면 전부).
- **테스트**: `tests/arcade-v43-skins.test.cjs` 3개(먼저 실패 기록 `docs/v43/tests-before-skins.txt`).
- **못 한 것**: 드라이브 연결 장애로 최근 2주 자산 조사, 하트 그림, 피격·사망·시전 동작 세트(CX-0070BM·CX0069BQ·CX-0068SM·CX-0079MM)는 미적용. 보스 피격·사망 동작과 나머지 보스 33명의 공격 자세도 여기에 달려 있다.

## 11. 최근 2주 드라이브 자산 적용과 7분야 심사 (2026-11-14 추가)
