# v43 전투·모바일·음향 개선 — 2026-11-17

적용 대상은 첫 화면에서 실행되는 `arcade.html`과 v43 엔진입니다. 예전 `?story` 전투 엔진의 난이도 규칙은 이번 변경 대상이 아닙니다.

## 전투 규칙

| 항목 | 노멀 | 헬 |
| --- | --- | --- |
| 탄 수·속도·패턴·레이저·피격 판정 | 헬과 동일 | 동일한 공격 규칙 |
| 시작 목숨 / 폭탄 | 기존 5 / 2 유지 | 기존 3 / 1 유지 |
| 피격점 접촉 시 자동회피 | 공격 단계에 따라 기존 7~37% | 없음 |
| 자동폭탄 | 회피 실패 후 폭탄 재고가 있으면 발동 | 없음 |
| 수동폭탄 | 버튼 또는 X | 버튼 또는 X |
| 스침 게이지 충전 | 기존처럼 폭탄 재고 충전 | 기존처럼 폭탄 재고 충전 |

같은 시드·플랫폼·입력 이력에서 적의 공격 규칙이 같습니다. 노멀의 자동폭탄이 발동하면 해당 탄막이 지워지므로, 그 이후의 실제 화면까지 항상 같은 것은 아닙니다. 모바일의 기존 성능 조정은 유지하며 모바일 안에서도 노멀·헬의 공격 규칙이 같습니다. 여유 난이도는 기존 완화 규칙을 유지합니다.

- 작은·중간·큰 구슬과 버블은 사격으로 파괴됩니다. 내구도는 각각 0.5 / 1 / 2 / 3입니다. 빠른 아군 탄의 이동 선분과 구슬 표면의 최초 접촉으로 판정합니다. 파괴된 분열탄은 추가로 터지지 않습니다.
- 쌀알탄·기물은 기존 회피 대상입니다. 폭탄의 기존 탄막 제거 기능은 유지합니다.
- 사슬·언덕 커튼의 통로가 한 번에 반대편으로 이동하던 규칙을 바꿔 다음 줄에서 최대 한 칸 이동하게 했습니다.
- 문양·룬·지그재그 레이저는 **1초 점등 → 1.5초 소등**을 반복합니다. 마지막 0.3초의 재점등 표시는 피해가 없습니다. 겹친 문양도 같은 박자를 사용합니다. 형태를 잘라 회피 공간을 만들지 않으며, 기존 문양은 소등 중 옅게 남습니다.

## 조작과 메뉴

- 저속은 게임 전체의 시간을 늦추는 기능이 아니라 **캐릭터의 정밀 이동과 피격점 표시**입니다. 모바일은 저속 버튼을 누른 채 다른 손가락으로 이동합니다. PC는 Shift를 누릅니다.
- 이동·저속·폭탄은 서로 다른 손가락을 추적합니다. 저속을 누른 손가락이 버튼 밖으로 이동해도 놓기 전까지 유지됩니다. 터치 취소·앱 전환·일시정지 때 눌림 상태를 정리합니다.
- 폭탄 터치는 한 번만 발동합니다. 키보드 접근성 동작도 지원합니다.
- 일시정지 버튼, Esc 또는 Space로 메뉴를 엽니다. 길게 누른 Esc가 메뉴를 즉시 닫는 문제와 재개 후 이동키가 남는 문제를 수정했습니다.
- 메뉴에서 BGM·효과음 각각 켜기/끄기·음량, 화면 흔들림, 절전 그래픽을 조절합니다. 설정은 이 브라우저에 저장되며 바꾸는 동안 전투는 멈춰 있습니다.

## 음향

이미 재생·예약된 효과음의 즉시 음소거, 일시정지와 재개, 모바일 오디오 컨텍스트 복귀, 재시작 시 이전 효과음 정리, 종료된 오디오 노드 해제를 수정했습니다. 존재하지 않던 폭탄 연타 효과음 이름도 연결했습니다.

BGM 볼륨 0, 늦게 완료된 재생 요청이 음소거를 해제하는 문제, 재개 지연, 빠른 곡 전환, 같은 파일의 불필요한 재시작, 실패 음원의 재시도를 수정했습니다. 브라우저 숨김과 네이티브 앱 백그라운드 상태를 분리했습니다.
