# 7대죄 보스 등장 대사와 actor 매핑

이 문서와 `src/arcade-boss-intros-v43.js`의 보스 대사는 게임 등장 연출을 위해 새로 쓴 **각색**입니다. 정본의 직접 인용 대사라고 주장하지 않습니다. 정본은 `docs/v43/canonical-story.txt`이며 원문과 기존 `arcade-story-v43.js`는 변경하지 않습니다. 각색은 원문에 있는 사건·욕망·소품만 사용하고, 선택 영웅의 정체성과 원전의 의목사 A 역할이 충돌하지 않도록 보스 자신의 두 마디로 구성했습니다. 각 항목의 `sourceExcerpts`는 해당 절에서 그대로 가져온 검토 근거입니다.

## 정확한 등장 맵

stageIndex는 0부터, 원전 장면 번호는 게임 SCENES의 번호입니다. 10개 actor는 새로운 10죄종이 아니라 **7죄종과 탐욕·교만의 후속 형태**입니다.

현재 main 보스 입장 필터만 적용하면 실제 누락되는 것은 `p2_chairman`입니다. 제2부의 `mb_14`~`mb_21`은 중간 파수체이며 위 보스들의 대체 ID가 아닙니다. 거미 중간보스 `mb_02`, `mb_24`와 잡몹 `spider`는 허용 목록에 들어가지 않습니다. 보라검 천사 `violet`은 별도 본보스이며 7대죄 분류가 아닙니다.

## 모듈 계약

브라우저 전역은 `HapilArcadeBossIntros`, Node에서는 CommonJS를 제공합니다.

- `getBoss(actor, stageIndex)`: 정확한 actor/장면 조합의 등장 대사. 목록에 없거나 조합이 다르면 `null`.
- `isSinBoss(actor)`: 후속 형태를 포함한 명시적 10개 actor 허용 목록.
- `BOSS_ENTRANCES`: 검토 가능한 10개 동결 항목.
- 항목: `actor,stage,sin,sinName,bossName,title,kind,durationMs,lines,sourceSection,sourceFile,sourceExcerpts,entrance,isSevenSin`.
- `kind`는 항상 `dialogue-adaptation`. `lines`는 `{speaker,text}` 두 개이며 각 줄은 60자 이내입니다.

다른 보스의 기존 정본 회상은 `Story.getStage(stageIndex)`로 계속 조회할 수 있습니다. UI에서 새 모듈의 대사를 사용할 때는 “등장 대사 · 정본 바탕 각색”처럼 원문 회상과 구별할 수 있습니다. stage21에는 회장과 연산핵이 함께 있으므로 컷신 시청 키는 stage만이 아니라 `stage:actor`로 구분해야 합니다. 이 데이터 모듈은 전투 시뮬레이션·탄막·레이저·입장 시 적탄 정리를 직접 변경하지 않습니다.
