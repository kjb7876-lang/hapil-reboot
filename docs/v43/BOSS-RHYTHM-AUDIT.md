# 첫 보스 공격의 실제 무피격 경로 검증

신규 리듬 공격이 적용되는 **51개 보스, 재등장을 포함한 57회 전투**의 첫 일반 카드를 실제 엔진으로 검사했다. 이지·노멀·헬, seed 1·17·12345, 일반·컴팩트 탄 배열을 조합한 **1,026개 사례가 모두 무피격 경로 탐색과 독립 재생을 통과**했다.

| 항목 | 기록 |
| --- | --- |
| 검증 단위 | 보스 방문 57회 × 난도 3종 × seed 3개 × 배열 크기 2종 |
| 실제 입력 재생 | 1,026회, 총 657,798 엔진 틱 |
| 첫 카드 길이 | 원래 제한 시간 360–637틱, 약 6–10.62초 |
| 고정 목표로 이동한 성공 경로 | 846개 |
| 위험을 예측하여 이동 방향을 바꾼 성공 경로 | 180개 |
| 피격·폭탄·자동폭탄·확률 회피 | 모두 0 |
| 검증 시작 | 실제 생성 위치 (180, 556), 기억사수, 기본 성장 상태 |

`boss-rhythm-audit.json`에는 모든 사례의 stage/segment, seed, 입력 RLE, 실제 종료 시각, 입력 해시와 엔진·리듬·보스 등장·영웅·파트 소스의 SHA256을 저장했다. 원래 첫 카드 시간은 늘리지 않았다. 보스 HP만 매 틱 충분히 높게 유지하여 자동 사격으로 일찍 격파되는 것을 막고 **원래 제한 시간 끝까지** 검증했다. 실제 게임에서는 높은 화력으로 더 일찍 격파할 수 있다.

입력은 앱과 같은 일반 이동 4.2px/틱, 저속 이동 1.8px/틱 이하로 제한했다. 위치를 덮어쓰거나 폭탄·피격 무적을 넣지 않았다. 자동폭탄 재고는 0, 확률 회피는 꺼진 상태다. 정상적인 등장 준비 및 전환 정리는 엔진이 수행하며, 검증 도구는 전투 중 위험물을 지우지 않는다. 실제 사격, 일부 큰 탄 파괴 후 작은 탄, 잡몹, 바닥, 상승 장애물도 그대로 처리한다.

처음에는 몇 가지 고정 목표 경로를 시도한다. 실패하면 현재 위험물 위치로부터 후보 이동을 기하학적으로 예측하는 정책을 사용한다. 각 시도는 **하나의 실제 엔진 상태만 진행**하고 한 번 맞으면 실패한다. 성공 입력 전체를 새 엔진에서 재생하여 피격 0과 원래 카드 종료를 다시 확인한다. 큰 상태 버퍼의 복제나 도중 상태 되돌리기는 하지 않는다.

## 재현

```sh
node --max-old-space-size=192 tools/audit-boss-rhythm-v43.cjs --output docs/v43/boss-rhythm-audit.json
node --max-old-space-size=192 tools/audit-boss-rhythm-v43.cjs --verify docs/v43/boss-rhythm-audit.json
node --max-old-space-size=192 --test tests/arcade-v43-boss-rhythm-audit.test.cjs
```

검증 테스트 3개는 전체 범위·입력 재생 외에도 정지해 실제로 피격되는 경로, 중간에 끊긴 경로, 폭탄 입력, 이동 속도 초과를 거부하는지 확인한다.

## 해석 범위

이 결과는 **지정된 시작 상태와 seed에서 각 첫 일반 카드를 통과하는 연속 입력이 실제로 존재한다**는 유한한 증거다. 이름 붙은 문양 공격, 첫 카드 이후, 모든 seed, 캠페인에서 가능한 모든 이전 상태, 다른 영웅의 사격 효과까지 보증하지 않는다. 예측 정책은 사람의 시야나 반응 시간을 모사하지 않으므로 사람이 쉽게 피할 수 있다는 보증도 아니다. 탐색이 실패해도 곧 회피 불가능하다는 뜻은 아니다.

신규 리듬의 휴지는 해당 보스의 신규 발사 휴지다. 남은 탄, 잡몹, 바닥, 상승 장애물까지 사라지는 시간이라는 뜻은 아니다. 8초 주기가 원래 카드 시간에 따라 일부만 반복될 수 있으며, 16초로 인위적으로 연장하지 않았다.
