# 세로판 수묵화풍 기준 (v43, 코드만)

세로판의 기본 화풍. 새 그림 없이 `src/ink-v43.js` 가 캔버스 그리기 길목에서 바꾼다. 주소에 `?ink=0` 을 붙이면 옛 화풍으로 돈다. 시각 심사는 이 한 장을 기준으로 한다.

## 색 체계
| 이름 | 값 | 쓰임 |
|---|---|---|
| 한지 | `#f2e9d6` | 바탕, 패널, 버튼 |
| 초묵 | `#1e1a18` | 윤곽 붓선, 글자, 흰 탄 |
| 농담 | 초묵~한지 사이 | 배경·인물의 명암(밝기 순위로 대부분 옅게, 가장 어두운 곳만 짙게) |
| 자주·주홍·쪽빛·석록·황토 | 원래 탄 색의 밝기를 뒤집고 채도를 절반으로 | 적 탄, 광선, 문양(보스 고유 색 유지) |
| 담묵 회색 | `rgb(84,78,80)` | 영웅 탄(적 탄 안료 색과 겹치지 않게) |
| 가라앉힌 인주 | `rgba(150,56,44,.8)` | 피격점 테(가운데는 먹 점) |

- 황토는 한지와 붙으므로 밝기 0.3 이하, 채도 0.6 이상으로 짙게 쓴다.
- 순백·형광·네온은 쓰지 않는다. 빛은 더하지 않고 먹처럼 겹칠수록 짙어진다(더하기 합성 → 곱하기).

## 붓 규칙
- 둥근 탄: 고르지 않은 둘레의 먹 점. 가장자리에 먹이 고이고 가운데는 물기로 옅다. 둘레에 옅은 번짐과 튄 방울 셋.
- 쌀알 탄: 붓 한 점. 머리는 짙고 꼬리는 갈라지며 마른다(진행 방향이 머리).
- 큰 방울 탄: 고리 없이 번진 먹 덩이(가운데가 짙고 둘레가 고르지 않다). 몹·영웅·탄을 감싸는 원 고리는 그리지 않는다(사용자 11-15).
- 인물·몹·보스: 먹 5단 농담으로 바꾸고 색은 14%(영웅 12%)만 남긴다. 바깥 윤곽에 붓선, 안쪽에 비백 점.
- 발치: 보스·몹은 드라이브 안개 프레임(fx-poison-mist)을 먹빛으로 바꿔 깔고, 영웅은 먹선 두른 흰 구름을 탄다. 영웅 둘레 하늘색 고리는 없애고 피격점은 가라앉힌 인주색.
- 굵은 선(2.6 이상)은 갈필 줄을 덧그린다. 메뉴·버튼은 한지색·명조·낙관.
- 바닥 압박 패턴(쌓이는 돌·지형)은 색을 뒤집지 않고 원래 짙은 바위색 그대로 둔다(`HapilInk.raw`). 뒤집으면 한지에 묻힌다.
- 배경: 번짐(흐림) 위에 윤곽 붓선, 먹 입자. 위아래 이음매는 유지한다.
- 화면: 한지 결(닥 섬유)과 가장자리 먹 번짐을 맨 위에 곱한다.
- 영웅 둘레의 큰 고리는 그리지 않는다. 피격점은 작고 가라앉은 색이되 늘 보인다.

## 지킬 것
- 탄 판정 크기·위치·속도는 바꾸지 않는다(그림만 바꾼다).
- 탄은 배경보다 늘 짙어야 한다. 배경 농담은 탄보다 옅게.
- 다른 게임·작품의 그림을 흉내 내거나 가져오지 않는다.

## 알려진 한계
- 별·비늘·단검·부적 모양 탄은 색만 바뀐 도형이다(붓 모양 미적용).
- 배경은 원화를 변환한 것이라 붓으로 그린 산수는 아니다.
- 그림은 처음 그릴 때 한 번 굽는다(장면이 바뀔 때 짧은 멈칫이 있을 수 있음, 실기기 미검증).
- 2차 심사(11-15) 지적: 배경이 중간 회색 얼룩에 몰려 여백이 적음, 흰 구름 영웅 대비 낮음, 하트와 주홍 탄 헷갈림, 광선·문양 선 굵기 일정, 도형 탄이 벡터 그대로, PC 패널과 플레이 칸 밝기 비슷.
- 끄기: 주소에 `?ink=0`.
