# 보스 행동과 회피를 잇는 연출 (2026-11-20)

사용자가 보낸 외부 연출 검토·제안서(`/검토`)를 읽고 타당한 것을 넣었다. 판정·점수·난수는 바꾸지 않았다(몹 쏘기 예고는 엔진이 `m.cueAt`만 적는다).
표시층은 새 파일 `src/arcade-cues-v43.js`(HapilCues), 검사는 `tests/arcade-v43-cues.test.cjs`.

## 넣은 것

| 장면 | 제안 | 넣은 방식 |
|---|---|---|
| 1장 정원 '가장 굵은 뿌리' | 보스 뒤 장식 원 옅게, 축에 먹 맺힘, 하단에도 축 | 광선 꼬리표 `cue:'root'`. 예고 동안 룬 결계·마법진이 22%로 물러나고, 축 맨 위에 먹이 고여 흘러내린다(붉은 예고선 위층). 영웅 가까운 아래에 인주색 붓 괄호로 같은 축을 짧게 찍는다(돕는 표시). |
| 16장 베엘제붑 '거대한 위장' | 접시를 기울여 먹점이 모이는 순간 위치 기억, 격파 뒤 빈 의자 옆 졸업사진(대사 없음) | 보스 앞 접시가 잡아 둔 방향으로 기울고 먹점이 모인다. 모이기 시작할 때 영웅이 서 있던 자리에 먹 점선 고리가 남아 그리로 쏟아진다(기존 조준 그대로). 격파 뒤 빈 의자와 기대 둔 졸업사진이 드러났다가 다음 맵 몹이 들어오면 걷힌다. 졸업사진은 정본 [탐식의 주방]. |
| 몹·중간보스 | 쏠 적이 몸을 틀고 총구에 먹, 퇴장은 총구를 거두고 | 편대는 박마다 다음 박에 쏠 몹을 같은 규칙으로 미리 골라 한 박(9~13틱) 앞, 홀로 쏘는 몹은 18틱 앞에 몸을 영웅 쪽으로 살짝 틀고 총구에 속 빈 먹 고리가 조여든다(탄과 구별). 물러나는 몹·영웅 아래로 빠지는 몹은 총구 없이 가던 방향 먹 자취만. |
| 소리 | 레이저와 솟는 먹물 분리 | 레이저는 기존 상승음, 솟는 먹물은 낮은 북 두드림(`inkSwell`). |
| 37장 대수문장 '짧은 틈' | 문이 잠길 때 금속음, 빗장 풀림 동기화 | 세로 명령 광선 `cue:'bolt'`. 예고 끝에 빗장이 밀려 잠기며 `gateClang`, 광선이 꺼지는 순간 빗장이 빠지며 `boltRelease`. |
| 46장 → 56장 | 환도 세 박자 복선 | 46장(장면 50) 마지막 격파와 56장 '세쌍둥이의 기록' 시작에 같은 `hwandoThree`. |
| 성장 | '주포 2→3발' | 공격 단계가 오르면 기존 알림 아래에 실제로 늘어난 것(주포·유도탄 발 수, 연사)을 쓴다. |
| 스펠 시작 | 기술명 + 보스 뒤 한지 잠시 비움 + 첫 획 소리 | 기존 기술명 띠·먹 조임에 더해 보스 뒤 장식 원이 약 0.7초 비고 한지빛이 깔렸다 돌아온다. 그 스펠 첫 탄이 나오는 순간 붓 쓸림 소리(`brushStroke`). |

## 넣지 않은 것과 이유

- 56장 교주 격파 순간·봉인 보너스 확정·세 번째 봉인 낙관 표시: 다른 스레드("보스 격파 순간·연습·가독성 개선") 담당.
- 44장 두 성주의 창이 함께 어두워짐, 45장 좌우 빗장: 배경 그림에 창·빗장 자리가 없어 새 그림이 필요하다(닷츠 요청 후보). 소리 복선은 46·56장으로 먼저 넣었다.
- 중간보스 제한시간 퇴각 자세: 11-19 규칙으로 보스·중간보스는 시간으로 사라지지 않아 해당 장면이 없다.
- 초견 5명 무음 테스트(통과 기준): 사람 실험이라 이 환경에서 못 한다. 미검증.
