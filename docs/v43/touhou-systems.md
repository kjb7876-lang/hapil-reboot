# 동방식 탄막 시스템 조사 보고서와 세로판 적용 기획 (2026-11-20)

사용자 요청(11-19 23:40 KST): "동방탄막겜의 시스템과 규칙 연출들 조사해서 보고서작성 및 기획해서 우리겜에 녹여주고 그후 실플레이해서 잘 적용되었는지 버그없는지 난이도 적절한지 개선할점 없는지 찾아서 개선후 배포".

이 문서는 세 부분이다. 1부는 조사, 2부는 무엇을 가져오고 무엇을 안 가져올지에 대한 기획, 3부는 이번에 실제로 넣은 것과 수치다.
탄 패턴 자체의 규칙은 `docs/v43/danmaku-rules.md`(11-19)에 따로 있다. 이 문서는 패턴이 아니라 **패턴을 둘러싼 시스템**(점수·자원·표시·연출)을 다룬다.

원칙: 다른 게임의 그림·캐릭터·글꼴·음악·고유 연출은 옮기지 않는다. 가져오는 것은 "위험을 무릅쓰면 보상이 커진다" 같은 규칙의 뼈대뿐이고, 겉모습은 이 게임의 수묵화풍(낙관·먹·한지)으로 새로 만든다.

### 1.2 시리즈 공통 뼈대

1. **작은 판정점과 저속 이동.** 캐릭터 그림이 아니라 약 5×5 픽셀 점으로 맞는다. 저속 버튼을 누르면 느려지고 점이 보인다.
2. **스침(graze).** 탄을 맞지 않고 아슬아슬하게 지나가면 탄 하나당 한 번 센다(광선은 계속 센다). 스침은 그 자체로 점수이고, 작품마다 다른 것을 올려 준다. 영야초는 별 아이템 값(스침 40회마다 +10), 요요몽은 스펠 보너스, 휘침성은 아이템 값(스침 10회마다 +10).
3. **스펠 카드.** 보스의 이름 붙은 공격. 선언하면 배경이 바뀌고 이름이 오른쪽 위에 뜬다. 시간 제한이 있고, 맞거나 필살기를 쓰면 보너스를 잃는다. 보너스는 시작값에서 **시간이 갈수록 줄어든다**. 풍신록은 시작 5초 뒤부터 `0.9 × 시작값 ÷ (제한시간 − 5)`씩, 요요몽은 `시작값 ÷ (제한시간 + 10)`씩 초마다 준다.
4. **수집선(point of collection).** 화면 위쪽의 보이지 않는 선. 그 위로 올라가면 화면의 아이템이 모두 빨려 오고 **최대값**으로 들어온다(최대값은 노란 글씨). 선 아래에서 먹으면 값이 낮다. 요요몽은 선 바로 아래에서 급격히 떨어지고 화면 맨 아래는 약 10%다. 풍신록부터는 조건 없이 늘 열려 있다.
5. **목숨·필살 자원.** 초기작은 점수나 아이템 개수로 목숨을 준다. 휘침성은 조각 방식이다(목숨 조각 3개 = 목숨 1, 필살 조각 8개 = 필살 1). 목숨이 가득이면 넘치는 몫은 필살로 바뀐다.
6. **피탄 직후 필살 창.** 맞은 직후 아주 짧은 시간(요요몽 0.1~0.3초) 안에 필살기를 누르면 그 한 대가 없던 일이 된다.
7. **보스 UI.** 체력 막대는 왼쪽 위, 일반 공격과 스펠이 색으로 나뉜다. **화면 맨 아래 가장자리에 보스의 가로 위치 표식**이 있고, 맞는 동안 옅어지며 체력이 낮으면 붉게 깜박인다. 영웅만 보고 있어도 사격을 맞출 수 있게 하는 장치다.
8. **결산.** 스테이지가 끝나면 스테이지 기본값 + 아이템 개수 + 스침 수(영야초·요요몽 모두 스침 1회당 500)를 더해 보여 준다.
9. **스펠 카드 기록.** 카드마다 도전 횟수와 봉인 횟수가 남는다.

### 1.3 왜 이 뼈대가 통하는가

- 스침·수집선·스펠 보너스는 모두 **"안전한 자리를 떠나면 보상이 커진다"**는 한 가지 원리다. 그냥 살아남는 것과 잘 플레이하는 것 사이에 눈에 보이는 차이를 만든다.
- 보너스가 **줄어드는 숫자**로 보이면, 같은 패턴도 "빨리·깨끗하게"라는 목표가 생긴다. 숫자가 고정이면 플레이어는 그 차이를 모른다.
- 수집선은 위쪽(보스 쪽)으로 올라가야 하므로 **언제 올라갈지**를 고르게 한다. 탄이 걷힌 틈을 읽는 재미가 생긴다.
- 보스 위치 표식·판정점·노란 최대값 글씨는 모두 **정보를 영웅 근처로 가져오는** 표시다. 탄을 보느라 위를 못 보는 장르의 약점을 메운다.

## 2부. 기획: 무엇을 녹일 것인가

### 2.1 이미 있던 것

| 뼈대 | 세로판 상태(작업 전) |
|---|---|
| 작은 판정점·저속 이동 | 있음. 판정점은 늘 작게 보이고 저속이면 고리까지 |
| 스침 | 있음. 스침마다 점수와 필살 게이지 |
| 스펠 카드·선언 연출 | 있음. 먹 번짐·이름 띠·페이즈 알약 |
| 봉인 보너스 | 있었지만 **고정값**이고 화면에 줄어드는 숫자가 없었음. 봉인해도 소리만 남 |
| 수집선 | 판정은 있었지만(y<190) **화면에 아무 표시가 없었음**. 플레이어가 존재를 알 수 없음 |
| 하트 값 | 높이에 비례했지만 스침과 무관, 받은 값이 화면에 안 뜸 |
| 보스 위치 표식 | 없음 |
| 조각 자원 | 없음(부가 바뀔 때만 목숨 1 회복) |
| 결산 | 별만 보임. 스침·봉인·보너스 내역 없음 |
| 카드 기록 | 없음 |

정리하면 **규칙은 절반쯤 있었지만 화면에 드러나지 않아 플레이어가 쓸 수 없었다.** 이번 작업의 중심은 새 규칙을 얹는 것보다 있는 규칙을 보이게 하고 서로 잇는 것이다.

| 결계·하이퍼류 게이지 | 넣지 않음. 스침 게이지 → 필살 재고가 이미 그 자리에 있다 |
| 원작 풍 글꼴·컷인 구도·효과음 | 넣지 않음. 복제 금지 |

### 2.4 난이도에 미치는 영향

- 탄속·탄 수·판정 크기(난이도 기준표)는 손대지 않았다.
- 유일한 자원 변화는 봉인 조각이다. 봉인은 "맞지 않고 필살기 없이" 넘긴 패턴에만 주어지므로 잘하는 플레이에 대한 보상이고, 못하는 플레이를 더 쉽게 하지는 않는다. 봇 측정은 3부에 있다.

### 3.3 실플레이 점검과 고친 것

방법: (가) 엔진 봇(선형 예측 회피)으로 구간을 통째로 돌려 수치를 본다. (나) 실제 페이지를 헤드리스 크롬(휴대폰 390×844, PC 1280×720)에서 열고, 시작 버튼부터 실제 UI로 들어가 페이지 안 봇이 키보드로 조작한다. 헤드리스 결과이므로 실기기·GPU 확인은 미검증이다.

| 실행 | 결과 |
|---|---|
| 실제 페이지, 이지·휴대폰 4.3분 | 오류 0건. 1스테이지 클리어, 2스테이지 진행. 수집선·받은 값·보너스 줄·결산 표시 확인 |
| 실제 페이지, 노멀·PC 4.3분 | 오류 0건. 1스테이지 클리어. 옆 HUD의 봉인·조각·하트값 표시 확인 |
| 실제 페이지, 이지·PC / 노멀·휴대폰 / 헬·휴대폰 (2차) | 오류 0건. 이지에서 봉인 1회, 낙관 찍힘 확인. 노멀·헬 봇은 1스테이지에서 쓰러짐(봇 실력 한계, 변경 전과 같음) |
| 엔진 봇, 이지 9~13·23~27스테이지 각 15분 | 완주. 봉인 7/17, 11/17. 분당 피격 0.73, 0.47 |
| 엔진 봇, 노멀 37스테이지·헬 49스테이지 | 봇이 첫 스테이지에서 쓰러짐. 분당 피격 2.8, 3.9 |

실플레이에서 찾아 고친 것:

1. 수집선 안내 글이 보스전 내내 탄 위에 떠 있었다 → 글은 처음 2.5초만, 그 뒤로는 점선만 남긴다. 알림 띠·낙관이 뜨면 숨긴다.
2. 봉인 낙관이 쓰러지는 보스 위에 겹쳤다 → 보스가 내려와 있으면 위쪽, 아니면 보스 아래에 찍는다. 스테이지 알림 띠가 있으면 그 아래로 내린다.
3. "봉인 놓침"이 패턴마다 가운데에 떠서 못하는 플레이에 같은 알림이 반복됐다 → 가운데 알림을 없애고, 보너스를 잃는 순간 이름 아래 줄이 한 번 깜박이게 했다.
4. 하트를 한꺼번에 거두면 숫자 여러 개가 영웅 위에 겹쳤다 → 합계 하나로 묶고 개수를 작게 붙인다. 영웅 머리 위로 띄운다.
5. 보스 위치 표식이 아래 HUD에 반쯤 가렸고 바닥 안개에 묻혔다 → 화면 고정층으로 옮기고 아래 테두리에 붙은 눈금 모양으로 바꿨다.
6. 스테이지가 뒤로 갈수록 봉인 보너스만 커지고 하트 값은 그대로라 하트가 무의미해졌다(23~27스테이지에서 봉인 149만 대 하트 4만) → 하트 기본값을 스테이지마다 +150.
7. 실제 게임은 페이즈 최소 시간 때문에 보스가 약 14초 전에는 쓰러지지 않는데 보너스가 그 전에 줄기 시작했다 → 줄기 시작하는 때를 20초로.

난이도: 탄속·탄 수·판정은 그대로라 분당 피격은 변경 전과 같다. 봉인 조각으로 얻는 목숨은 이지 봇 기준 5스테이지에 1개 안팎이고, 목숨이 가득이면 필살기로 바뀐다. 노멀·헬에서 봇은 봉인을 거의 못 했다. 조각은 잘하는 사람만 받는 보상으로 동작한다.

7전문가 심사(시각 7분야, 서로 독립): 1차 평균 7.21(미달) → 낙관 쪽지 재질·수집선 대비·받은 값 가림·보스 표식 크기를 고친 뒤 2차 평균 7.37(재시도 기준 6.7 초과). 2차 지적 가운데 낙관과 수집선 겹침, 보스 표식 모양, "합계 ×개수" 표기는 그 뒤에 고쳤고 이 마지막 손질은 재심사하지 않았다.

남은 지적: 받은 값 글씨가 PC 판에서 작다. 낙관이 찍히는 순간의 번짐이 정지 화면에서 약하다. 보너스가 줄어드는 것을 막대로도 보여 주면 전투 중에 더 잘 읽힌다.

### 3.4 다음에 하면 좋은 것

- 낙관·받은 값의 그림을 닷츠 자산으로 교체(지금은 코드로 그린 임시 그림).
- 봉인 기록을 한눈에 보는 "봉인첩" 화면(패턴 목록과 도전/봉인 횟수).
- 스펠 연습 모드(봉인첩에서 패턴 하나만 골라 다시 하기). 보스 체험 모드가 이미 있어 진입점만 만들면 된다.

## 11-20 외부 심사 반영(격파 순간·연습·가독성)
- **체력 소진**: 소진한 틱에 봉인 보너스를 굳힌다(`bonusLock`). 지금 소절은 끝까지 쏘지만(11-19 '시전한 패턴은 모두'), 다음 소절·특수 페이즈·반사탄·중앙 견제·배경 압박은 새로 시작하지 않는다(`markDown`·`downFiring`). 이미 예고된 광선·문양이 꺼지면 쓰러진다. 끝까지 맞지 않으면 굳힌 값을 그대로 받는다. 화면: 보스 아래 붓 띠 '격파 · 봉인 확정'(1.6초), 위쪽 줄 '봉인 확정 +N · 버티면 지급', 빈 체력 막대.
  - 교주의 사몽(노멀, 무적 자동 사격 재측정): 소진→쓰러짐 15.1~17.5초 → 0.8초, 받은 보너스 232,230~245,590 → 295,000. 스테이지 6.3분 → 4.2분.
- **스펠 연습**: 결과 화면 '방금 맞은 스펠 다시 연습 「이름」'(마지막으로 맞거나·자동 필살·봉인을 놓친 이름 붙은 패턴). 엔진 `spellOnly`는 그 카드 하나만 하고 끝난다. 진행 기록·봉인 기록·최고점에 넣지 않는다.
- **최고점 분리**: localStorage `hapil-arcade-bests-v43` = 난이도별 {원코인, 연습}. 예전 전체 최고점(`hapil-arcade-best-v43`)은 그대로 둔다.
- **탄 몰림 가독성**: 탄 수·켜진 광선·문양으로 몰림(0~1)을 재어 배경·날씨·스펠 문장 위에 바탕색 막(최대 42%)을 깔고 아군 검기·번개를 최대 50% 옅게. 판정 있는 문양·적탄·피격점·보스는 그대로.
- **30초 조작 실습**: 여정을 처음 시작할 때 한 번(이동 240px → 저속 1초 → 필살 1번, 단계마다 최대 10초, 건너뛰기). 자동 검사 브라우저(navigator.webdriver)는 건너뛰고 `?drill=1`이면 보인다. 기록 키 `hapil-arcade-v43-drill`.
