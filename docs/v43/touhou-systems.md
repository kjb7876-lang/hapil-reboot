# 동방식 탄막 시스템 조사 보고서와 세로판 적용 기획 (2026-11-20)

사용자 요청(11-19 23:40 KST): "동방탄막겜의 시스템과 규칙 연출들 조사해서 보고서작성 및 기획해서 우리겜에 녹여주고 그후 실플레이해서 잘 적용되었는지 버그없는지 난이도 적절한지 개선할점 없는지 찾아서 개선후 배포".

이 문서는 세 부분이다. 1부는 조사, 2부는 무엇을 가져오고 무엇을 안 가져올지에 대한 기획, 3부는 이번에 실제로 넣은 것과 수치다.
탄 패턴 자체의 규칙은 `docs/v43/danmaku-rules.md`(11-19)에 따로 있다. 이 문서는 패턴이 아니라 **패턴을 둘러싼 시스템**(점수·자원·표시·연출)을 다룬다.

원칙: 다른 게임의 그림·캐릭터·글꼴·음악·고유 연출은 옮기지 않는다. 가져오는 것은 "위험을 무릅쓰면 보상이 커진다" 같은 규칙의 뼈대뿐이고, 겉모습은 이 게임의 수묵화풍(낙관·먹·한지)으로 새로 만든다.

### 1.2 시리즈 공통 뼈대

1. **작은 판정점과 저속 이동.** 캐릭터 그림이 아니라 약 5×5 픽셀 점으로 맞는다. 저속 버튼을 누르면 느려지고 점이 보인다.
2. **스침(graze).** 탄을 맞지 않고 아슬아슬하게 지나가면 탄 하나당 한 번 센다(광선은 계속 센다). 스침은 그 자체로 점수이고, 작품마다 다른 것을 올려 준다. 영야초는 별 아이템 값(스침 40회마다 +10), 요요몽은 스펠 보너스, 휘침성은 아이템 값(스침 10회마다 +10).
3. **스펠 카드.** 보스의 이름 붙은 공격. 선언하면 배경이 바뀌고 이름이 오른쪽 위에 뜬다. 시간 제한이 있고, 맞거나 필살기를 쓰면 보너스를 잃는다. 보너스는 시작값에서 **시간이 갈수록 줄어든다**. 풍신록은 시작 5초 뒤부터 `0.9 × 시작값 ÷ (제한시간 − 5)`씩, 요요몽은 `시작값 ÷ (제한시간 + 10)`씩 초마다 준다.
4. **수집선(point of collection).** 화면 위쪽의 보이지 않는 선. 그 위로 올라가면 화면의 아이템이 모두 빨려 오고 **최대값**으로 들어온다(최대값은 노란 글씨). 선 아래에서 먹으면 값이 낮다. 요요몽은 선 바로 아래에서 급격히 떨어지고 화면 맨 아래는 약 10%다. 풍신록부터는 조건 없이 늘 열려 있다.
5. **목숨·필살 자원.** 초기작은 점수나 아이템 개수로 목숨을 준다. 휘침성은 조각 방식이다(목숨 조각 3개 = 목숨 1, 필살 조각 8개 = 필살 1). 목숨이 가득이면 넘치는 몫은 필살로 바뀐다.
6. **피탄 직후 필살 창.** 맞은 직후 아주 짧은 시간(요요몽 0.1~0.3초) 안에 필살기를 누르면 그 한 대가 없던 일이 된다.
7. **보스 UI.** 체력 막대는 왼쪽 위, 일반 공격과 스펠이 색으로 나뉜다. **화면 맨 아래 가장자리에 보스의 가로 위치 표식**이 있고, 맞는 동안 옅어지며 체력이 낮으면 붉게 깜박인다. 영웅만 보고 있어도 사격을 맞출 수 있게 하는 장치다.
8. **결산.** 스테이지가 끝나면 스테이지 기본값 + 아이템 개수 + 스침 수(영야초·요요몽 모두 스침 1회당 500)를 더해 보여 준다.
9. **스펠 카드 기록.** 카드마다 도전 횟수와 봉인 횟수가 남는다.

### 1.3 왜 이 뼈대가 통하는가

- 스침·수집선·스펠 보너스는 모두 **"안전한 자리를 떠나면 보상이 커진다"**는 한 가지 원리다. 그냥 살아남는 것과 잘 플레이하는 것 사이에 눈에 보이는 차이를 만든다.
- 보너스가 **줄어드는 숫자**로 보이면, 같은 패턴도 "빨리·깨끗하게"라는 목표가 생긴다. 숫자가 고정이면 플레이어는 그 차이를 모른다.
- 수집선은 위쪽(보스 쪽)으로 올라가야 하므로 **언제 올라갈지**를 고르게 한다. 탄이 걷힌 틈을 읽는 재미가 생긴다.
- 보스 위치 표식·판정점·노란 최대값 글씨는 모두 **정보를 영웅 근처로 가져오는** 표시다. 탄을 보느라 위를 못 보는 장르의 약점을 메운다.

## 2부. 기획: 무엇을 녹일 것인가

### 2.1 이미 있던 것

| 뼈대 | 세로판 상태(작업 전) |
|---|---|
| 작은 판정점·저속 이동 | 있음. 판정점은 늘 작게 보이고 저속이면 고리까지 |
| 스침 | 있음. 스침마다 점수와 필살 게이지 |
| 스펠 카드·선언 연출 | 있음. 먹 번짐·이름 띠·페이즈 알약 |
| 봉인 보너스 | 있었지만 **고정값**이고 화면에 줄어드는 숫자가 없었음. 봉인해도 소리만 남 |
| 수집선 | 판정은 있었지만(y<190) **화면에 아무 표시가 없었음**. 플레이어가 존재를 알 수 없음 |
| 하트 값 | 높이에 비례했지만 스침과 무관, 받은 값이 화면에 안 뜸 |
| 보스 위치 표식 | 없음 |
| 조각 자원 | 없음(부가 바뀔 때만 목숨 1 회복) |
| 결산 | 별만 보임. 스침·봉인·보너스 내역 없음 |
| 카드 기록 | 없음 |

정리하면 **규칙은 절반쯤 있었지만 화면에 드러나지 않아 플레이어가 쓸 수 없었다.** 이번 작업의 중심은 새 규칙을 얹는 것보다 있는 규칙을 보이게 하고 서로 잇는 것이다.

### 2.2 넣는 것

| # | 이름 | 규칙 | 겉모습(이 게임 것) |
|---|---|---|---|
| 1 | 줄어드는 봉인 보너스 | 시작값 `20000 + 스테이지×5000`. 20초 뒤부터 40초에 걸쳐 1/3까지 줄어든다. 맞거나 필살기를 쓰면 0 | 패턴 이름 아래 금빛 숫자가 실시간으로 준다. 놓치면 회색 "봉인 놓침" |
| 2 | 봉인 낙관 | 봉인하면 받은 값을 크게 보여 준다 | 인주색 낙관(도장) "封"이 내려와 찍히고 옆에 값과 조각 수. 인주색은 플레이어를 돕는 순간 전용이라는 기존 규칙에 맞는다 |
| 3 | 봉인 조각 | 봉인 3번마다 목숨 1. 목숨이 가득이면 필살 1 | 낙관 옆에 "봉인 조각 1 / 3" |
| 4 | 스침 → 하트 값 | 하트 한 개 값 `500 + 스침×10`(최대 5000) | HUD 스침 옆에 "하트값" |
| 5 | 수집선 표시 | 선 위에서는 모든 하트를 최대값으로. 선 아래는 높이에 따라 30~100% | 하트가 떠 있을 때만 점선과 한 줄 안내. 선 위에 있으면 금빛. 여정 첫 5초에도 한 번 보임 |
| 6 | 받은 값 표시 | — | 거둔 자리에 값이 뜬다. 최대값은 금빛, 한꺼번에 거두면 합계 ×개수 |
| 7 | 보스 위치 표식 | — | 화면 맨 아래 인주색 삼각 표식. 맞는 동안 옅어지고 체력 20% 아래면 깜박임 |
| 8 | 스테이지 결산 | `(스테이지+1)×2000 + 스침×20 + 무피격 5000 + 무필살 3000` | 스테이지 알림 띠에 "봉인 2/3 · 스침 87 · 결산 +9,740" |
| 9 | 봉인 기록 | 패턴마다 난이도별 [도전, 봉인]을 기기에 저장 | 보너스 숫자 옆에 "2/5" |

### 2.3 넣지 않는 것과 이유

| 뼈대 | 판단 |
|---|---|
| 시간 초과로 넘어가는 스펠·버티기 스펠 | 넣지 않음. 사용자 규칙(11-19) "보스·중간보스는 시간으로 사라지지 않고 체력으로만" |
| 스펠 종료 시 탄을 아이템으로 바꾸기 | 넣지 않음. 사용자 규칙(11-19) "탄은 맵 밖으로 나가야만 사라진다(필살기 예외)" |
| 피탄 직후 필살 창 | 넣지 않음. 이지·노멀은 자동 필살이 이미 같은 역할을 한다. 헬에 넣어 보았으나 "헬은 접촉 즉시 목숨"이라는 기존 검사와 충돌했고, 0.13초 창은 터치 화면에서 체감이 거의 없다 |
| 점수로 목숨 주기 | 넣지 않음. 조각 방식 하나로 충분하고, 난이도 기준표(PR 132~133)의 목숨 수를 흔들지 않기 위해 |
| 결계·하이퍼류 게이지 | 넣지 않음. 스침 게이지 → 필살 재고가 이미 그 자리에 있다 |
| 원작 풍 글꼴·컷인 구도·효과음 | 넣지 않음. 복제 금지 |

### 2.4 난이도에 미치는 영향

- 탄속·탄 수·판정 크기(난이도 기준표)는 손대지 않았다.
- 유일한 자원 변화는 봉인 조각이다. 봉인은 "맞지 않고 필살기 없이" 넘긴 패턴에만 주어지므로 잘하는 플레이에 대한 보상이고, 못하는 플레이를 더 쉽게 하지는 않는다. 봇 측정은 3부에 있다.
