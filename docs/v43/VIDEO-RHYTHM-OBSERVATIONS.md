## 합일에 적용할 수 있는 설계 제안 — 아래 숫자는 영상 복원값이 아님

1. **발사 묶음과 휴지를 갖는 대체 패턴**: `emit()`에 `local=t%480`을 넘기는 8초 구간. 고유 소품 팬 → 명확한 조준 예고 → 교차 레이저 2줄 → 신규 발사 휴지로 구성한다. 정확한 각 단계 길이와 속도는 합일의 이동 속도·탄 크기로 검증한다. 기존 패턴 위에 추가하지 않는다. `signature()`의 `strands`/`spray`가 휴지를 계속 채우지 않도록 신규 생성만 제어한다.
2. **3연 고리의 도착 박자**: 기존 `delayedRing`을 3회 발사한 뒤 휴지. 예시값은 0.4초 간격, `duration:1.2`, 2.4초 반복, `baseSpeed:78`, `speedStep:-6`. 후발 고리가 앞 고리를 추월해 통로를 닫지 않도록 한다. 실제 탄 수에는 `waveCount()`의 난이도·밀도 배수가 붙으므로 최종 탄 수와 실제 통과 폭을 검사한다.
3. **나선 방향의 교대**: 기존 `spiral`의 발사 각도 회전을 다음 묶음에서 반대로 바꾼다. 이미 발사한 탄은 갑자기 역주행시키지 않는다. 두 나선을 계속 중첩하는 대신 하나의 압박 묶음과 이동 시간으로 읽히게 한다. 영상의 선회 나선은 시각 참고이며, 개별 탄의 실제 궤도 알고리즘을 복원한 것은 아니다.

문양레이저는 모양을 지우지 않고 기존 점등·소등 박자를 유지한다. 자연 휴지는 새 발사를 쉬는 시간이며, 기존 탄을 임의로 지우는 시간이 아니다. 반면 보스/패턴 클리어 전환은 영상처럼 위협을 정리하고 안전한 등장 상태로 넘어가야 한다. 정밀 이동과 보통 이동 모두에서 연속 회피 경로를 검증하고, 자동폭탄·무적 완주를 회피 가능성의 증거로 쓰지 않는다.

분석용 연락판은 작업 중 검토에 사용한 프레임이며 배포 자산이 아니다. 구현은 보스 첫 일반 공격을 대체하는 리듬 모듈에서 진행하며, 영상의 정확한 알고리즘 복원이나 원본 자산 복제를 의미하지 않는다. 실제 추가 수치와 회피 검증은 리듬 모듈·검증 기록을 기준으로 한다.
