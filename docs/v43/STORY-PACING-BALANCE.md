# 정본 서사 · 진행 시간 · 탄막 규칙 (2026-11-17)

## 적용 범위
기본 실행되는 arcade.html/v43. 첨부 정본의 62구역을 기존 56전투에 대응시킨다. 전투 수와 구간 ID를 보존하며, 6개 연결 장면과 프롤로그·최종장은 데이터와 원문에 보존한다. 자동 등장 연출은 56전투의 짧은 기억 발췌이며 전체 정본을 모두 자동 재생하는 기능은 아니다. 규칙 메뉴에서 전체 원문을 열 수 있으며 Android 오프라인 묶음에도 포함한다.

노멀·헬은 같은 탄 수·탄속·피격점·공격 생성 규칙을 쓴다. 여정의 반복 횟수·길이는 다르므로 실제 전체 화면 순서가 항상 동일하다는 뜻은 아니다. 이지는 보스전의 새로운 바닥/솟는 그림 생성과 문양의 보조 난사 중첩을 줄인다. 문양 자체를 자르지 않고 기존 점등/소등으로 통과한다. 경로에 들어선 뒤 이전 공격이 남는 경우도 경로 검사에 포함한다.

구간 연습과 작성된 전체 패턴 검사는 원래 길이를 유지한다. 실제 여정 및 정상 저장 이어하기는 단축 규칙을 적용한다. 이전 구간 ID와 저장한 성장값은 그대로 읽는다.

## 보스 연출과 조작
첫 보스 입장에서 약0.75초 등장 후 정본 화자의 기억2줄을 표시한다. 원문에 없는 보스 직접 대사는 추가하지 않는다. 기본 자동 진행 약6초, 다음/건너뛰기/자동 진행 해제 지원. 읽은 장면은 다음 시도에서 생략하며 시작 화면에서 다시 보기 기록을 초기화할 수 있다. 연출 중 전투 시계와 피해는 멈추며 Esc로 설정을 열었다 돌아와도 이어 읽는다. 대화 뒤 누적 프레임을 몰아서 처리하지 않는다.

## 기본 탄막 규칙
- 공격은 자동. 캐릭터 중심의 피격점을 지키며, 저속은 캐릭터의 정밀 이동이다.
- 스침은 직접 피격과 구별되며 게이지를 채운다. 충전된 폭탄 재고는 최대치가 있다.
- 구슬/버블은 사격으로 깨며 쌀알/기물탄은 피한다. 파괴된 분열 구슬은 추가 분열하지 않는다.
- 문양레이저는1초 점등/1.5초 소등. 소등 마지막0.3초 재점등 표시는 무해하다.
- 헬은 자동회피/자동폭탄이 없다. 노멀·이지 자동방어는 피격점 접촉 시 적용한다.
- 탄막마다 대응 가능한 경로를 만드는 것이 목표다. 잘못 진입한 모든 위치에서 탈출을 보장한다는 뜻은 아니다.
- 원코인은 추가 컨티뉴 없이 한 여정을 완료하는 기준이다. 저장 이어하기·스테이지 선택·보스 연습 기록은 순수 신규 여정과 구분한다.

## 측정과 검증
전체 사격 추적 모델은 실제 주포·성장·아이템·시간제한을 쓰고 폭탄을 사용하지 않는다. 진행 시간을 측정하기 위해 피해만 막는다. 따라서 인간 숙련도·회피·원코인 가능성의 증명이 아니다. 대화/일시정지/로딩 시간은 엔진 측정에 포함되지 않는다. 표준 목표 시간을 맞추려고 보스 처치 뒤 강제로 기다리게 하지 않는다.

최종 전체 측정은 이지53.17분, 노멀88.27분, 헬117.04분(대화 제외)이다. 연출 예산5분을 더하면58.17/93.27/122.04분이다. 제한시간 종료는 각각1/30/36구간으로, 모든 보스를 사격으로 처치한 실행은 아니다. 재현: `node tools/measure-arcade-pacing-v43.cjs gentle` (또는normal/hell). 정해진 시드의 경로 검사와 실제 고정 입력 재생은 별도로 수행한다. 모든 플레이 이력을 검증하거나 실기기 조작감·소리를 직접 청취한 것은 아니다.
