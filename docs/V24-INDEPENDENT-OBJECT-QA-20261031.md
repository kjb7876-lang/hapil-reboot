# v24 독립 탄환 원화·전투 표시 검수

보스 고유 공격 원본을 구체·혼합 이펙트로만 표시하던 부분을, 구분되는 실제 물체로 표시하는 변경을 검수한다. 색욕은 하이힐·립스틱·깨진 하트, 질투는 전체 거울 칼날, 탐욕은 전체 동전 톱날을 사용한다. 원화는 소유가 확인된 합일1 자료이며 새 인물·결말을 추가하지 않는다.

이 문서와 대응 JSON은 **native CPU Canvas·명시적 면역 fixture 검증**이다. 실제 브라우저 입력·소프트웨어/실제 GPU·모바일 에뮬레이션·실제 휴대폰 FPS·자연 체력 플레이와 구분한다. 본문에서 제시하는 완주한 경로는 없다. 실제 브라우저와 전체 회귀 결과는 루트의 최종 검수 보고서를 따른다.

## 확인 방식

- 합일1 원본 3개의 해시 및 닫힌 알파, 256×256 파생 파일의 실제 바이트를 확인한다. 하이힐의 붉은 가죽, 립스틱의 금색 케이스·붉은 내용물, 갈라진 하트는 서로 다른 원본이다.
- 색욕 24사례와 질투·탐욕 16사례를 실제 표시 크기·두 방향·두 품질로 그린다. 단순 도형 그리기나 다른 이미지의 뒷받침 없이 한 실제 원화 본체로 표시한다. 큰 두 물체의 각도는 별도로 9단계씩 확인한다.
- 기존 원/캡슐 전체의 픽셀 중심에서 alpha≥128인 비율이90% 이상이고, 작은 중앙부의 불투명 표시율이80% 이상인지 확인한다. 전체 판정과 작은 중앙 접점의 검사는 서로 다른 항목이다.
- 큰 하이힐·립스틱과 거울은 기존4px보다 장식 영역이 넓다. 새 순수 원화 물체는 작은48px·큰100px의 명시적 한도를 갖고, 기존 다른 탄환과 탐욕은 기존4px 한도를 유지한다. 정적인 격리 캔버스는256×256·중심128을 사용하며 alpha>8 픽셀이 바깥 가장자리에 닿지 않는지도 확인한다.
- 새 립스틱의 회전은 실제 원본을 같은 변환으로 넓은 참조 캔버스에 그린 알파 총량과 대조한다. 먼저 회전한 작은 프레임에서 원화가 잘린 뒤 맞추는 오류를 허용하지 않는다.
- 실제 HELL의 두 회전탄은 둘 다 paletteSlot0이다. 반대 spinRate 부호가 각각 하이힐과 립스틱으로 이어지는지 **실제 코어 발사 기록**으로 확인한다. 좌우가 같은 이미지가 되는 오류를 피한다.
- 기본·여유·헬, 기존 전투 규칙과 combatRevision21의3페이즈를 모두 검사한다. 명시적 면역·자동 공격/스킬 끔 상태에서18경우×840틱을 진행하고 배포된v23 월드·체크포인트와 비교한다.
- 색욕 전체 탄환과 승인된 질투·탐욕 ORB를 제외한 다른 탄환140사례, 모든 자산 구성의v23 레이저148사례는 원시RGBA가 바이트 단위로 같은지 대조한다. 질투·탐욕의 칼날과 두 보스의 레이저는 변경 예외가 아니다.
- 두 큰 투척·세 일반 원화·활성 광선이 함께 있는 실제 HELL0/2페이즈235틱 장면을 두 품질로6회씩 그린다. 예열 후 스탬프·광선 캐시 재제작0,96개/4MiB 한도를 확인한다. 단순한768개 반복 fixture만으로 실제 혼합 장면의 캐시 안정성을 보증하지 않는다.

## 디버깅 이력

최초 후보는 작은 중앙 접점 검사를 통과했지만 큰r11 원형 판정의 실제 표시율은 하이힐 약48%, 립스틱 약44~52%였다. 작은 거울·하이힐·립스틱도 약59~69%였다. 일부 투명 영역에서 원형 피격이 발생할 수 있는 관찰된 회귀였으므로, 첫 검사 결과를 최종 통과로 사용하지 않았다.

게임 코어와 기존 피격 원/캡슐을 그대로 두고, 실제 원본의 단단한 부분을 피벗으로 삼아 순수 원화만 키워 기존 판정을 포함하도록 수정했다. 원이나 다른 물체를 아래에 덧그리지 않았다. 따라서 길게 돌출된 굽·끝·장식 일부는 기존 판정보다 바깥이며 그 끝 자체에 새 피해가 생긴 것은 아니다.

립스틱을 회전시키던 캐시도 원본 알파 약0.885%를 잘랐다. 같은 회전의 더 넓은 참조와 대조한 독립 시험은99.115% 보존으로 실패했다. 새 원화의 회전 캐시 크기를 넓혀 원본이 들어간 뒤 전체를 맞추도록 고쳤다. 초기 실패 로그와 최초 피격 가시성 측정은 `docs/v24-qa`에 보존한다.
