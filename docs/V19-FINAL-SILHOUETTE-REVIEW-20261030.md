# 최종 탄환 실루엣 검토 — 2026-10-30

최종 후보의 실제 `HapilProjectiles.drawBullet()`을 CPU Canvas로 한 번 호출 묶음으로 렌더하고, 저장된 세 장의 실제 픽셀을 직접 확인했다. 최종 후보에서 **배경이 불투명 사각 카드처럼 남는 구체적인 추가 차단 결함은 발견하지 못했다.**

대상은 표시 그룹 0~35와 한리안·백이온의 분리된 소유자 분기, 총 37개 표시 경우다. 이는 본편 35개 전투 구성에 독립 교주 연습과 두 번째 인물 분기를 더한 수치이며 정본 보스 인물 수가 아니다. 각 경우에서 반경 3/6의 orb 및 halfLength7 needle을 실제 크기와 4배 최근접 확대로 대조했다. 실제 스탬프 렌더 148개이며 각 렌더를 두 크기로 제시했다. 각도 0, age0.25, 첫 팔레트의 대표 상태 검사다.

확인한 수정은 다음과 같다.

- 뿔악마: 부분 원형 술식의 잘린 면 대신 같은 소유자의 완전한 와류 윤곽.
- 타락천사 기사: 잘린 검 장식 내부 대신 완전한 자기 대검의 검끝과 가드.
- 악몽 우두머리: 사각형으로 잘린 파동·칼자루 내부 대신 자기 본체 원화의 실제 굽은 날.
- 교주 및 독립 연습: 잘린 축/내부 질감 대신 자기 창의 닫힌 꼬임 코어 윤곽.

원형으로 그려진 원본 물체는 원형일 수 있다. 이 검토는 원·모든 단순한 모양을 임의로 금지한 판정이 아니라 원화의 윤곽 및 잘린 불투명 배경판 여부에 대한 판정이다. 작은 반경3 탄환이 원화의 모든 세부를 노출한다고 주장하지 않는다. 보스별 큰 스킬·예고·자세, 충돌 판정, 자연 진행, GPU·실제 휴대폰 성능은 각각의 별도 검증 대상이다.

재현: `node tools/review-all-projectile-glyphs-v19.cjs`. 이 도구는 projectiles/story-assets/media 소스 해시를 렌더 전후 비교하며 도중 변경되면 인증하지 않는다. 최종 해시 및 이미지 SHA는 동명의 JSON에 남겼다. 이번 검토자는 생산 코드나 기존 79개 게임 이미지를 수정하지 않았다. 최종 고정 소스에서 한 차례의 전체 대조를 마쳤으며 추가 변경이나 구체적인 새 결함이 없으면 반복하지 않는다.
