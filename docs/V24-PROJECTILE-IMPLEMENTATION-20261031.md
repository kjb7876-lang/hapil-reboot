# v24 보스 전용 물체 탄환 구현

최종 후보 `src/projectiles.js` SHA-256: `3e4938f4d03bd6c1154313a813a5253334a1d45caeab00afdffe5d9a6f0bcebc`.

합일1에서 확인한 색욕의 독립 하이힐·립스틱·깨진 하트 원화를 사용한다. 원래 하나의 복합 공격 이미지를 구체·바늘·회전탄 모두에 재사용하던 표시를 세 가지 실제 물체로 구분했다. 새 인물·결말·전투 규칙을 추가하지 않았다. 모든 선택은 이미 존재하는 탄환의 종류·패턴·팔레트 슬롯·회전 방향을 읽으며 코어 객체를 변경하지 않는다.

## 실제 패턴과 물체 연결

| 기존 코어의 공격 | 표시할 물체 | 선택 기준 |
|---|---|---|
| 색욕 1페이즈의 양쪽 부채꼴 | 하이힐 / 립스틱 | `asmodeus-phase-1`의 슬롯0 / 슬롯1 |
| 색욕 2페이즈 고리 | 깨진 하트 | `asmodeus-phase-2` 구체 |
| 색욕 3페이즈 교대 부채꼴 | 하이힐 / 립스틱 | `asmodeus-string-curtain`의 슬롯0 / 슬롯1 |
| 압박·분신 등 나머지 구체 | 깨진 하트 | 위의 전용 부채꼴이 아닌 구체 |
| 기존 바늘·긴 탄체 | 립스틱 | 실제 `halfLength > 0` |
| HELL의 두 회전 투척체 | 하이힐 / 립스틱 | 실제 `spinRate < 0` / 반대 방향 |

두 HELL 투척체는 원래 둘 다 `paletteSlot:0`이다. 따라서 팔레트만으로 두 물체를 구분하지 않았다. 물리 회전 부호는 벽에 튕기거나 이동 방향이 바뀌어도 유지되므로 물체가 비행 중 다른 것으로 바뀌지 않는다. 바운스·가속·탄속·탄환 수·피해 반경·예고 시각은 그대로다. GENTLE/NORMAL도 원래 양쪽 부채꼴과 고리에서 세 물체를 볼 수 있다. 새 전투21의 3페이즈 연습에서는 압박 하트와 전용 투척이 겹친다.

새 HELL 하이힐·립스틱은 각각 한 번 그리는 완전한 실제 탄체다. 이전의 복합 색욕 효과를 위에 다시 덮지 않는다. 투척 예고에도 서로 다른 원본 두 개를 표시한다. 원본 정적 이미지를 회전시키는 것이며 새 연속 원화 애니메이션이라는 뜻은 아니다.

## 원화·가독성

루트가 실제 픽셀을 확인한 256×256 투명 WebP 세 개를 사용한다. 키는 `h24LustHeel`, `h24LustLipstick`, `h24LustBrokenHeart`다. 모두 필수 자산이며 누락·잘못된 크기는 전투 전에 차단한다. 원본·파생 경로와 해시는 `V24-RUNTIME-PROJECTILE-ASSETS-20261031.json`과 출처 검수 기록을 참조한다.

붉은 구두의 재질, 립스틱의 금색 케이스와 붉은 끝, 분홍빛 하트의 균열을 일괄 단색으로 지우지 않는다. 원본 RGB를 유지하고 기존 가속·휘어짐·정지 역할에는 작은 비율의 보스 고유색만 섞는다. 이 표시는 실제 행동에 따라 매 프레임 깜박이는 효과가 아니라 발사 시 정해진 역할을 따른다.

이미지의 투명 여백과 조준 회전 뒤 생긴 여백을 캐시 제작 때만 계산하고, 실제 알파 경계를 균등 확대·축소한다. 좁은 립스틱과 하이힐이 구체·캡슐 크기에 따라 납작하게 찌그러지지 않게 했다. 립스틱의 원래 대각 장축을 약60도 돌려 비행 방향에 맞추며, 하트는 서 있는 모양을 유지한다. 실제 불투명 덩어리의 피벗과 원본 알파에서 측정한 내부 반경을 사용해, 기존 피해 원이 실제 몸체 안에 보이도록 크기를 맞춘다. 하이힐·립스틱·하트와 질투의 거울은 명시적인 새 장식 크기 한도인 작은 탄체48px·큰 투척체100px를 적용한다. 이들의 실제 바깥선은 이전4px 여유를 넘어갈 수 있으며 그 부분은 추가 피해를 주지 않는다. HELL 하이힐은 약80~90px, 립스틱은 약70~80px의 큰 물체로 보일 수 있다. 이전36px 복합 덧그림을 중복하지 않는다.

추가로 기존 합일1 원화의 두 구체를 개선했다. 질투는 중앙 눈만 잘라 쓰던 대신 깨진 거울 물체 전체를, 탐욕은 큰 복합 재질 대신 금화 톱날 전체를 보인다. 질투 피벗은 원본 `[350,256]`의 녹색 홍채(RGBA69,236,98,252), 탐욕은 `[256,256]`의 금속(RGBA201,125,27,253)이다. 실제 탐욕 원화의 `[320,240]` 구멍은 알파3이므로 피벗으로 쓰지 않았다. 이 둘은 일반 구체에만 적용하고 기존 칼날·회전탄·레이저는 유지한다. 질투 구체 역시 큰 원형 판정이 작은 눈 조각 밖으로 보이지 않게 원본의 단단한 눈 부위에 맞춰 확대한다. 탐욕은 이전의 작은 표시 여유로도 실제 피해 원이 보이므로 불필요하게 확대하지 않는다.

## 비용과 검증

일반 탄환과 새 색욕 HELL 물체는 실시간에 이미지 한 번만 그린다. 기존96개/4MiB 캐시 상한을 유지한다. 바뀌지 않은 탄환과 탐욕은 최대4px 표시 여유를 유지하며, 명시한 색욕3종·질투 거울에만48/100px 전체 물체 한도를 적용한다. 캐시 준비 후 알파 탐색·픽셀 읽기·캔버스 생성은 하지 않는다. 초기 캐시 제작 비용은 존재한다. 전체 게임·실제 휴대폰의 지속 FPS는 별도 검증 대상이다.

새 `projectileArtRevision:24`, `projectileVariantDraws`, `projectileVariantSourceKeys`가 실제 적용된 물체와 원본 키를 보고하며, 진단 결과의 객체 복사는 내부 집계를 수정하지 않는다. `maxVisualOutset`는 실제로 커진 장식 여유까지 정직하게 보고하며, `legacyMaxVisualOutset`는 바뀌지 않은 물체만 보고한다. `ownedObjectDraws`, `maxOwnedObjectPixels`, `ownedObjectExtentByVariant`와 작은/큰 물체 한도도 별도로 기록한다.

새 검사4개가 립스틱의60도 조준 회전에서 전체 알파 질량·투명 경계, 필수 자산 실패 처리, 실제 패턴 역할별 물체·원본의 한 번 그리기, 립스틱의 붉은 끝·금색 케이스, 양쪽 회전탄의 서로 다른 원본, 두 품질 일치, 불변 객체, 방향 전환 뒤 동일 물체, 예열 캐시 재사용·해제를 확인했다. 관련 기존 검사14개도 통과했다. CPU 렌더 검사이며 브라우저·실제 기기·자연 체력 전체 진행 결과로 부르지 않는다.

기존 두 시험 파일의 갱신은 명시적으로 바뀐 자산 계약뿐이다. `legacy-sins-projectiles.test.cjs`는 새 필수3종을 로드하고 색욕의 목록·누락 검사를 새 계약에 연결했다. `legacy-h14-source-skills.test.cjs`는 필수3종을 로드하고 색욕 회전탄이 복합 몸체+덧그림2회에서 단독 물체1회로 바뀐 단언과 실제 누락 원본을 갱신했다. 기존 중앙 알파·색 세부·전체 해제·시계·불변성 단언은 유지했다. 크기를 키운 물체의 표시 범위 단언만 새48/100px 한도로 분리하고 다른 물체의 기존4px 한도는 유지했다. 독립 `independent-projectile-detail-v19.test.cjs`에서도 색욕·질투 구체에만 명시적인 새 물체 한도를 적용하고 중앙 가시성0.8·색 세부·두 품질 동일 기준은 바꾸지 않았다. 초기 fixture 누락으로 실패한 로그와 수정 뒤14개 통과 로그를 보존한다.

초기 후보에서 립스틱을96×96 캐시 안에60도 회전하면서 알파 약1.71%가 잘리는 결함을 독립 검수에서 발견했다. 새 원본색·균등 비율 모드의 직각이 아닌 회전에만 충분한132×132 내부 캐시와4px 여백을 확보한 뒤 알파 경계를 측정하도록 수정했다. 기존90도 칼날·다른 탄환·레이저 경로는 유지했다. 새 검사는 실제 캐시의 알파 전체 합이 별도512×512 여유 캔버스의 같은96px 회전 참조와 정확히 같고, 실제 캐시 외곽2px가 투명함을 확인한다. 수정 뒤 관련17개와 새4개 검사가 각각 통과했다.

최종 전체 회귀와 독립 실제 코어·픽셀 검수 결과는 루트의 최종 배포 검증 기록을 따른다. 큰 회전 물체의 불투명 중심 확인은 전체 원형 피해 영역의 표시를 보증하지 않으므로, 독립 검수의 전체 충돌 영역 가독성 결과도 별도로 따라야 한다.

큰 물체 검수에서는 초기의 불투명 피벗만으로 기존 반경11 전체를 표현할 수 없다는 결함도 발견했다. 초기 약30px 하이힐·립스틱은 실제 원형 피해 영역의 약48~52%만 알파128 이상으로 보였다. 원형 배경이나 다른 이미지를 덧대는 대신 원본 자체의 단단한 부위를 선택하고 물체 전체를 키웠다. 256px 파생의 하이힐 피벗 `[57,62]`·내부 반경34.0588, 립스틱 `[115,154]`·39.0512, 밝은 하트 부위 `[134,122]`·68.1175를 사용한다. 이는 파생 이미지를 중앙 정렬한 `[128,128]`과 구분되는 실제 표시 피벗이다. 확장한 립스틱 캐시의 새 피벗에도 샘플96px와 캐시132px의 비율을 반영한다. 크기는 기본적으로 `(기존 반경+0.8)/캐시 내 단단한 영역 반경`으로 계산하고, 실제 원본 알파의 모든 회전 방향 지름에 전체 물체 한도를 적용한다. 실제 코어 객체와 판정은 그대로다. 전체 원·캡슐 가시성90%와 캐시 재사용·실제 화면은 독립 검수로 확인한 뒤 배포한다.
