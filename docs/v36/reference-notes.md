# v36 전투 시각 참고 — 1차 자료와 적용 해석

확인일: 2026-11-03. STRIKERS 1945와 동방영야초의 공식 배포 자료를 확인했다. 아래의 **관찰**과 **합일에 적용할 설계 판단**을 구분한다. 스크린샷만으로 발사/피격 애니메이션의 정확한 지속시간·실행 비용·판정·속도 수치를 확인했다고 주장하지 않는다.

## 1. STRIKERS 1945 — 공식 설명

- 원문: https://psikyo-portal.com/pressrelease_200422.html
- 발행: Psikyo / City Connection 공식 포털, 2020-04-22.
- 확인된 내용: 세로 슈팅이며, 서로 특징이 다른 여섯 기체, 강화에 따른 보조 무기, 대형 공격, Shot/Auto Shot/Bomb 구분을 설명한다.
- 설계 판단: 합일의 플레이어 탄환도 단순히 전부 밝게 만드는 대신, 기존 공격 종류·소유 캐릭터의 형상을 유지하면서 핵심 탄체와 사격 흐름이 읽히게 구분한다. 새 무기나 피해 수치를 도입한다는 의미는 아니다.

## 2. STRIKERS 1945 — 공식 실제 화면

- 공식 갤러리: https://psikyo-portal.com/shootinglibrary.html
- 해당 페이지의 STRIKERS 1945 화면: https://psikyo-portal.com/images/title/strikers1945_02.jpg
- 두 번째 화면: https://psikyo-portal.com/images/title/strikers1945_03.jpg
- 발행: Psikyo / City Connection 공식 포털.
- 직접 관찰: 어두운 전투장 위에서 자탄은 초록·파랑 계열의 가늘고 길쭉한 위쪽 사격 흐름으로, 적탄은 주황 계열의 작은 점유 면적으로 분리된다. 여러 플레이어의 사격도 길이·색·배열이 다르다. 정지 화면에서 확인 가능한 형태·대비·배열 관찰이다.
- 설계 판단: 기존 합일의 소스 탄체에 세로 방향의 밝은 중심과 짧고 절제된 꼬리를 부여한다. 적탄의 외곽과 중심이 최상위로 읽히도록 아군 장식의 넓이·알파를 제한한다. 1945의 비행기, 픽셀 탄환, 배경, 효과음을 가져오지 않는다.

## 3. 동방영야초 — ZUN 공식 화면 설명과 실제 화면

- 공식 매뉴얼: https://www16.big.or.jp/~zun/html/th08man/html/view.html
- 매뉴얼의 실제 화면: https://www16.big.or.jp/~zun/html/th08man/html/view00.jpg
- 공식 스냅샷 목록: https://www16.big.or.jp/~zun/html/th08ss.html
- 발행: 上海アリス幻樂団 / ZUN. 원문은 구형 일본어 인코딩으로 일부 검색 뷰에서 글자가 깨진다. 이미지 자체를 열어 확인했다.
- 직접 관찰: 주 전투장과 우측 상태 영역이 분리되어 있다. 어두운 배경 위 청록·파랑 탄막은 밝은 중심과 명확한 외곽을 가지고, 나선형 경로의 간격과 위상이 연속적으로 보인다.
- 설계 판단: 합일에서 피격 장식·사격 잔광이 적탄의 위치를 덮지 않도록 배치 순서와 지속시간을 제한한다. 기존 아트의 형상을 선명히 보존하며, 단순한 흰 원이나 새로운 기하 탄환으로 대체하지 않는다. 이번 작업에서 UI 위치·탄막 판정·회피 통로를 바꾼다는 의미는 아니다.

## 합일의 피격 표현에 대한 별도 설계 판단

위 정지 화면은 적 피격의 매 프레임 변화나 총구 섬광의 지속시간을 증명하지 않는다. 다음은 참고 자료의 대비/정보 분리 원칙과 기존 합일의 제약을 결합한 독자적인 설계 판단이다.

- 총구 섬광은 실제 발사 순간의 짧은 강조로 사용하며, 발사되지 않은 탄환을 약속하지 않는다.
- 적 피격은 실제 명중 위치의 작고 방향성 있는 충격을 먼저 보여 주고 빠르게 사라지게 한다. 지속적인 전신 흰색 덮어쓰기나 화면 전체 번쩍임을 피한다.
- 적 사망은 기존 자체 소스의 연기·파편·마법 흔적을 짧게 이어 붙인다. 주변 적탄을 가리는 큰 불투명 폭발을 기본값으로 삼지 않는다.
- 미세 잔광을 위해 시뮬레이션 개체를 늘리기보다, 확정된 사건을 읽는 렌더 전용 상태·프레임 재사용·상한 있는 버퍼를 우선 검토한다.
- 금빛·청록색의 아군 계열과 핏빛·검붉은색·보라색의 적대 계열은 스토리월드의 기존 그림체 기준을 따른다.

외부 이미지·음원은 런타임 자산으로 도입하지 않았다. 공식 참고 화면은 CC0 자산이 아니며 재배포 가능한 무료 게임 자산이라고 표시하지 않는다. 조사용 이미지 사본은 저장소 밖 임시 경로에서만 열었다. 이 문서에는 링크와 관찰/해석만 기록한다.
