# v24 전투·저장·원본 보존 검수

배포된 v23 main `72f1b2657d1a340fdad22b3179cbcc474628c993`과 대조했다. 코어·저장·예고 렌더링·배우·스토리/무기 계약·기존 미디어를 포함한 **301개 파일**이 바이트 단위로 같다. 런타임 변경은 `src/app.js`, `src/media.js`, `src/projectiles.js`이다. app은 진단 버전만, index는 캐시 질의만 바뀌었다.

기존 미디어 키 **281개**의 경로를 모두 보존하고 독립 색욕 물체3종 별칭만 추가했다. 기존 이미지/오디오 파일에 덮어쓰기가 없으며, 새 미디어 파일도 승인된3종뿐이다. 레이저 핵심 함수4개와 캐시96개/4MiB 상한은 그대로다.

별도 임시 디렉터리에서 원본3종을 다시 변환해 인코딩된 WebP 바이트·디코딩 RGBA를 파생본 매니페스트 및 제품과 대조했다. 원본 Git blob/SHA와 실제 소유 코드도 대조했다. 재생성은 제품·원본 파일을 수정하지 않았다. 파생본의 preparationCenter는 PNG 제작 중심일 뿐 실제 충돌 피벗 보증이 아니다. 최종 렌더링의 원본 내부 피벗·물체별 큰 장식 예산·전체 충돌 원 가독성은 독립 픽셀 검사를 따로 따른다. 상세 출처·해시는 JSON에 기록한다.

색욕 투척물 선택은 실제 코어의 고정 회전 부호, 일반 공격은 기존 패턴 ID·팔레트 슬롯을 사용한다. 나이·속도·반사 방향·난수로 도중에 물체를 바꾸지 않는다. 실제 반사·가속·충돌 반경과 저장·조작은 원래 코드가 소유한다. 일반 탄환의 원본색·비율 표시는 해당3구성에만 변경하며 레이저 표시는 유지한다. 새 solid-source 배치를 사용하는 지정 물체는 기존 피해 원이 실제 원본의 불투명한 부분 안에 놓이도록 크게 표시한다. 이 장식의 최대 지름은 일반48px·큰 투척물100px이며 물리 판정 확대가 아니다. 다른 모든 기존 물체의4px 장식 예산은 그대로다. 전체 피해 원 가독성 통과는 별도 최종 픽셀 검사가 맡는다.

독립 픽셀/실제 코어 면역 장면 검사는 별도 v24 보고서를 따른다. 이 문서를 새 자연 체력 완주·실제 브라우저 저장 경합·실제 기기 지속 FPS 통과로 표시하지 않는다.
