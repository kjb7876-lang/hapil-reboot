검수 모듈 준비 중

이 페이지는 검수 전용 DB만 사용합니다. 게임의 저장 DB를 열거나 삭제하지 않습니다. 두 탭에 같은 run 값을 사용하고 tab=A, tab=B로 구분하세요. 이미 기록이 있다면 새 run 값을 사용합니다. 초기화·삭제 버튼은 없습니다.

게임플레이 검사가 아닙니다. 경계 1은 실제 코어가 만든 최초 경계이며, 경계 2는 무적 fixture로 다음 안전 경계까지 진행해 수집합니다. 연습 기록도 실제 코어가 생성합니다. 자연 진행·성능 검증으로 계산하지 않습니다.

  1. A와 B에서 각각 최신 기록을 불러와 revision 0을 확인합니다.
  2. A 경계 1 저장 → B 설정 저장은 충돌 → B 최신 기록 불러오기 → B 설정 저장 성공.
  3. A 경계 2 저장은 충돌 → A 최신 기록 불러오기 → A 경계 2 저장 성공, 백업은 경계 1.
  4. A 연습 저장 차단·변경 없음 확인 → 실제 DB 재열기·코어 복원 확인 → JSON 내보내기.
