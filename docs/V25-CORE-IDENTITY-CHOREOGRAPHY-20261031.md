# v25 전투 규칙과 보스별 압박 탄막 개선

v25는 기존 35개 전투 구성 중 색욕을 제외한 34개 구성의 공통 압박 보조 탄막을 보스와 사건별 안무로 교체한다. 기존 각 페이즈의 본래 패턴, 레이저 압박 면적, 일반 적, 정본의 사건 순서와 결말은 보존한다. 모든 주공격을 새로 제작했다는 의미는 아니며, 35명을 새 보스로 추가한 것도 아니다.

`src/core.js` SHA-256: `0931918bc6517c6ad73a5f442922765149b35a2d40bd60d32c811cf70950e851`.

## 저장과 규칙 분리

- 규칙 미지정 및 `combatRevision:21`은 기존 결정적 동작을 유지한다. `COMBAT_REVISION` 내보내기도 21을 유지한다.
- 새로운 안무는 명시적인 `combatRevision:25`에만 적용한다. `IDENTITY_COMBAT_REVISION`은 25다.
- 체크포인트는 들어온 21 또는 25를 그대로 저장하고 복원한다. 기존 저장을 자동 승격하지 않는다.
- 색욕의 25는 전투 월드와 체크포인트의 버전 표기 외에는 21과 동일하다. 기존 하이힐·립스틱·깨진 하트의 v24 구현도 유지한다.
- 이미 열린 구버전 탭의 저장 보호는 별도 `storage.js`의 `combatContract:25`로 검사한다.

## 새로운 안무

## 공격 예고와 용량

- `boss.identityCasts`의 시전 예고는 방출 54틱 전에 고정한다. `warningAt`, `activeAt`, 출발점, 방향과 실제 탄환 사양은 확정 후 변하지 않는다.
- 예고는 동시에 최대 4개다. 최근 방출 뒤 12틱의 표시를 포함하는 기록은 최대 8개다. 별도 폴리곤 피해 판정을 만들지 않는다.
- 한 그룹은 헬 7개, 노멀 5개, 여유 모드 3개 이하다. 보스별 주기는 기존 공통 보조 탄막 주기 이상이므로 이 레이어의 그룹 수를 늘리지 않는다.
- 실제 방출은 약속한 `activeAt`에만 한다. 탄환 풀이 부족하면 그룹 전체를 취소하며, 나중에 지연 방출하지 않는다.
- 확정한 압박 통로와 닿을 새 탄환은 전체 직선 경로에서 제거한다. 플레이어 반지름과 바늘·검의 길이를 포함한다. 기존 본래 공격 전체가 이 통로를 비운다고 주장하지 않는다.
- 기존 탄환 상한 768개, 레이저 상한 40개와 활성 압박 구간의 헬 66%·노멀 44%·여유 22%, 접근전 70% 배율을 유지한다. 면적 수치는 전투 내내의 공격 점유율이 아니다.
- 25의 분신은 첫 방출 72·90틱 전에 충분한 예고를 제공한다. 환영은 기존 72틱 방출을 유지하면서 18틱에 예고를 시작한다. 모두 기존 허용된 적대 행위자의 공격이며 보호 대상이나 새 인물을 만들지 않는다.
- 보스가 쓰러지거나 다음 페이즈·접근전으로 넘어가면 아직 방출하지 않은 예고는 취소한다. 이미 발사한 탄환과 레이저는 기존 전환 처리대로 남는다.

실제 발사 탄환과 발사 이벤트는 `identityRole`, `identityCastId`, `identityWarningAt`, `identityActiveAt`를 연결하며, 25의 비색욕 탄환에는 발사 당시 `sourcePhase`를 기록한다. 한리안·백이온 및 분신의 `sourceActorId`와 `modelActorId`를 유지한다.

## 이번 작성자의 검증

`tests/boss-identities-core-v25.test.cjs`와 `docs/v25-qa/core-identity-targeted.log`에 기록한다.

- CPU 결정적 구현 검사: 색욕 3난도 × 3페이즈 × 840틱의 전체 전투 월드를 21과 비교한다. 버전 표기 외 차이가 없다.
- CPU 무적 fixture: 비색욕 34구성 × 3페이즈 × 1,200틱 헬 전투에서 각 정체성의 실제 방출을 확인한다. 총 122,400틱이며 관측 탄환 최고 307개, 풀 부족으로 누락한 그룹 0개다.
- CPU 무적 fixture: 실제 탄환의 출발점·방향·시전자·페이즈가 예고와 맞고, 예고 후 54틱에 방출되는지 확인한다. 동시에 대기하는 예고 4개, 기록 8개 상한도 검사한다.
- CPU 구현 검사: 34개 주 시전의 실제 기하·속도·정지·가속 사양이 서로 다르다. 단순 역할 라벨만 다르게 만든 구성이 아니다.
- CPU 보호 대상 검사: 기존 보호 대상 16구성에는 새로운 분신이나 시전 인물을 추가하지 않는다. 최종전은 코어 보존과 교주 권한 표적 의미를 유지한다.

이는 실제 휴대전화 성능, 실제 GPU, 자연 진행 완주 또는 화면 그래픽의 검증 결과가 아니다. 실제 화면과 일반 체력, 저장·다중 탭 검증은 별도 독립 QA 기록과 배포 검증을 함께 확인해야 한다.
