# 저장·재개 안정성과 전투 가독성 보완

## 변경 범위

- 진행/구간 저장을 검증하고 정상본을 `.backup`에 보관한다. 손상본은 `.invalid`에 남기고 정상 백업을 읽는다. 지원하지 않는 버전은 덮어쓰지 않는다.
- 저장 공간 부족 등 쓰기 실패를 표시하고 재시도한다. 진단 통계가 손상되어도 게임과 진행 저장을 중단시키지 않는다.
- 첫 구간을 포함해 저장된 성장치를 그대로 복원한다. 예전 저장에 성장치 필드가 없으면 기존 스테이지 시작값을 사용한다.
- 이어하기는 기존과 같은 **구간 재시작**이다. 체력·남은 폭탄·점수·탄막 위치의 순간 복원 기능을 추가한 것이 아니다. 메뉴에 이 동작을 안내한다.
- 배경 먹 대비를 낮추고 기존 탄과 장애물 실루엣의 한지색 가장자리를 보강한다. 적 탄·레이저는 전경 장애물보다 나중에 그린다.
- 스테이지 마지막 보스 격파 즉시 결과를 기록하고 90틱(일반 속도 약 1.5초) 동안 전투를 멈춘다. 짧은 격파 안내 뒤 기존 다음 구간으로 이동한다. 일시정지는 이 대기도 멈춘다.
- 보스의 일반 페이즈, 중간보스, 시간초과 진행 방식은 유지한다. 공격/성장 공식·난이도·충돌 크기·탄막 패턴은 변경하지 않는다.

## 검증

아래 관련 회귀검사 86개 통과. 56개 스테이지의 마지막 보스 전환, 중복 보상 방지, 저장 손상/백업/용량 부족/미지원 버전, 기존 저장 호환을 포함한다.

```sh
node --test --test-concurrency=2 \
  tests/arcade-v43-save-recovery.test.cjs \
  tests/arcade-v43-clear-transition.test.cjs \
  tests/arcade-v43.test.cjs \
  tests/arcade-v43-hero-memory.test.cjs \
  tests/arcade-v43-mobile.test.cjs \
  tests/arcade-v43-boss-melt.test.cjs \
  tests/arcade-v43-ink-risers.test.cjs \
  tests/arcade-v43-riser-see-through.test.cjs \
  tests/arcade-v43-riser-break.test.cjs \
  tests/arcade-v43-floor-pressure.test.cjs \
  tests/arcade-v43-no-rings.test.cjs \
  tests/arcade-v43-scripts-parse.test.cjs
```

성장치 필드가 없는 예전 저장의 호환성 보완 후 저장/전환/성장/파싱 28개를 다시 실행해 통과했다. 앱 정적 번들 생성도 통과했다.

실제 이미지와 운영 렌더러를 Native Canvas2D/VM에서 실행해 장애물·적탄 중첩과 클리어 문구를 확인했다. 같은 하네스에서 격파 즉시 저장, 전환 중 일시정지, 다음 스테이지 한 번만 진입, 손상 저장 복구, 실패 안내와 재시도를 확인했다.

이 검증은 실제 브라우저·휴대폰 플레이나 FPS 측정이 아니다. Chromium 실행은 환경의 소켓 권한 제한으로 시작 전에 실패했다. 전체 저장소 테스트가 아닌 위 관련 검사만 실행했다.

## 공개 배포 전 기기 확인

1. 기존 저장이 있는 PC/모바일에서 이어하기 → 탭 숨김 → 복귀 → 앱 재실행을 확인한다.
2. 1·2스테이지 보스 격파 때 저장, 약 1.5초 대기, 다음 단계 진입이 한 번씩 발생하는지 확인한다.
3. Android Chrome/iOS Safari에서 터치 이동, 작은 화면의 안내문, 장애물 위 적탄을 확인한다.
4. 저장 차단 상태에서 안내가 표시되고, 저장 기능 복구 후 다시 저장되는지 확인한다. 개발자 모드의 배속은 전환 대기에도 적용된다.
