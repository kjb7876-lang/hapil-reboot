# V23 레이저 재질 구현

최종 `src/projectiles.js` SHA-256: `72e42480e7aec149bceaf0fa355674cf6cf6100587a4221c661906fcdc56be90`.

일반 탄환, 전투 규칙, 저장 형식은 유지하고 레이저 표시만 변경했다. 원본 파일을 새 이미지로 대체하지 않았다. 보스별 기존 공격·무기·연결 광선의 실제 픽셀을 재사용한다. 원본별 파일·해시는 독립 픽셀 검수 보고서의 `sources`에 기록한다.

## 표시

- 실제 피해 캡슐 전체를 그리는 기존 세 구간의 소스 알파는 유지한다. 레이저에만 사용하는 별도 캐시에서 색을 조정해, 보스의 주색을 따르는 어두운 바깥층과 좁은 밝은 중심을 만든다. 보조 팔레트도 해당 보스의 원래 주색을 바깥층에 유지하고 밝은 중심·가벼운 색 혼합으로 구분한다. 보라 이름 보스의 넓은 보조 광선 전체가 흰 띠가 되는 현상도 줄였다. 일반 탄환·시전 효과는 이 레이저용 캐시를 사용하지 않는다.
- 기존의 한 장을 길게 늘리는 덧그림은 512×96 픽셀의 소스 재질로 교체한다. 세로형 원본 검은 가로 광선 방향으로 정렬한다. 원본의 명암과 알파를 사용하며, 단색 도형을 대체 몸체로 그리지 않는다.
- 높은 품질에서는 같은 원본의 측면 필라멘트가 광선 방향으로 흐르고, 실제 시작점에 작은 소스 이미지 효과가 표시된다. 이는 기존 단일 이미지의 이동·색 조정이며 새로 그린 연속 애니메이션이라는 뜻은 아니다.
- 모든 효과는 기존 피해 캡슐 내부로 잘린다. 예고 단계에 활성 몸체가 나타나지 않는다. 잔광에는 추가 흐름·발사점 효과가 없으며, 기존 `0.35 × (1-progress)` 투명도와 코어의 잔광 시계를 따른다.
- 넓은 압박 광선의 활성 기본 투명도 0.72와 일반 광선의 1.0은 유지한다. 밝은 원본을 그대로 확대한 넓은 흰 띠가 시야를 덮는 현상을 줄이기 위해, 두 번째 검수에서 기본 소스 구간까지 레이저 전용 색 조정을 적용했다.

## 비용 제한

재질·흐름·발사점 캐시는 한 소스/팔레트당 430,080바이트다. 기존 공용 캐시의 96개/4MiB 제한을 지킨다. 제작용 임시 캔버스는 즉시 픽셀을 해제하고, 유지되는 모든 캔버스도 제거 시 해제한다. 캐시는 해당 소스·팔레트를 처음 그릴 때 생성된다. 이 최초 제작 비용은 존재하며, 캐시가 준비된 프레임에서는 픽셀 읽기나 캔버스 생성 없이 이미지만 그린다. 이 구현만으로 실제 모바일의 최초 프레임 지연이나 지속 FPS가 검증되었다고 볼 수 없다.

최대 40개 광선의 기본 몸체는 모두 표시한다. 높은 품질의 추가 효과는 프레임당 최대 12개 광선에만 적용한다. 각 추가 광선은 흐름 1~2회, 발사점 1회 그리기로 제한된다. 낮은 품질에서는 추가 효과 없이 같은 기본 재질을 유지한다. 블러·필터·동적 입자를 추가하지 않았다.

`laserArtRevision`, `beamMaterialDraws`, `beamFlowDraws`, `beamEmitterDraws`, `beamDetailedLasers`, `beamDetailLimit`, `beamCacheBuilds`, `beamFrameCacheBuilds`, `beamSourceKeys`로 적용 상태를 확인할 수 있다. 기존 `sourceBeamOverlayDraws`는 광선당 재질 한 장이라는 의미를 유지한다.

## 검증

새 CPU 캔버스 검사 4개는 40개 광선의 기본 몸체 누락 여부, 추가 효과 상한, 캐시 준비 후 캔버스 재생성 없음, 전체 해제, 정확한 활성/잔광 구분, 입력 객체 불변성, 한리안/백이온 및 보조 팔레트의 개별 캐시를 확인한다. 마지막 검사는 보라검천사의 두 팔레트·두 품질 모두에서 넓은 바깥층이 보라색을 유지하고 밝기가 중심부에 집중되는지 실제 픽셀로 확인한다.

기존 `combat-copy-presentation-v21.test.cjs`의 정확히 4회 그리기 단언만 새 표시 구조에 맞게 조정했다. 이 시험의 시계가 0인 높은 품질에서는 기본 4회 + 흐름 1회 + 발사점 1회, 낮은 품질은 기존처럼 4회다. 기본 3구간의 활성 투명도, 네 번째 재질의 낮은 품질 계수 0.92, 기존 잔광 시계, 전투 객체 불변성 단언은 유지했다. 별도 새 시험에서 일반 시계의 최대 2회 흐름을 확인한다.

두 번째 후보는 관련 기존 검사와 새 검사 22개가 통과했다. 최종 색 조정 후보의 새 검사 4개도 통과했다. 이는 CPU 소스 렌더링 검사 결과이며 실제 기기·GPU·모바일 FPS 인증은 아니다. 최종 전체 검사와 독립 픽셀·브라우저 검수 결과는 배포 검증 기록을 따른다.
