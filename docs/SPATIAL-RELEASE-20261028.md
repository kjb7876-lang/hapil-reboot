## 변경

- 새 원문의 정원·뼈 동굴·검은 늪·재와 사슬·시체 언덕·일곱 기둥·병원·주사실·가면·J인장 공간 단서를 각색 구간명과 안내에 반영했다. 모바일에도 보이는 이동 패드에 간결한 공간 단서를 표시한다.
- 발록의 기존 레이저 예고를 원문의 바닥 흔적·내려오는 검과 연결했다. 같은 기존 경고 footprint 안에 짙은 밑선을 넣어 밝은 배경 대비를 높였다. 공격 기하·탄환 수·피해·경고 및 활성 시점은 바꾸지 않았다. 새로운 보스 이미지나 미완성 자산의 대체를 추가하지 않았다.
- 연습 HUD는 보스 순번 대신 현재 패턴 1/3을 표시한다.
- 앞선 모바일 CPU/배경 최적화, 연습 저장 분리, 지연·실패 저장, 짧은 터치, FPS 선택 보존과 실제 발사 이벤트 자세 연결을 함께 반영한다. 저장 namespace와 schema는 보존한다.

## 검증과 제한

`npm test`: Node/모의/CPU Canvas 19개 통과, 실패·건너뜀 0. 기존과 27,000틱 비교에서 새 표현 메타데이터를 제외한 상태가 동일했다(무적 fixture, 자연 완주 아님). 일반/경량 경고 픽셀의 변화는 기존 capsule 안에만 있고 활성 빔·잔광은 기존과 같았다.
