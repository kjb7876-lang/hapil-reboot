첫 후보의 작은 그림은 기존 원형 피격 영역 절반가량만 덮는 회귀가 있었다. 그림에 없는 피해를 남기지 않도록 실제 불투명 부위의 반경을 측정하고 피벗·표시 크기를 바꿨다. 명시한 새 물체만 전체 회전 외곽 기준 일반48px/큰100px 제한을 사용한다. 기존 피해 원은 그 안의 단단한 재질에 들어가며, 길게 뻗은 장식 끝까지 피해가 추가되는 것은 아니다. 다른 물체의 기존4px 장식 제한은 그대로다. 도형·다른 보스 이미지로 불투명한 판정을 덧칠하지 않았다.

립스틱 내부 회전의 잘림은 여유 있는 캐시와 정확한 피벗 변환으로 수정했다. 넓은 참조 캔버스와 전체 알파를 대조한다. 첫 전체 검사311개 중3개가 실패한 로그도 보존했다. 실제 중심 표시 기준80%는 낮추지 않고 수정했다. 나머지는 새 필수 이미지3종이 빠진 테스트 준비 목록을 보완하고, 옛 미디어 바이트 전체 동일 조건을 기존281경로·옛바이트접두부 보존 및 승인된3개만 추가 조건으로 바꿨다. 새 전체 피해 표시90% 검사도 추가했다.

코어·저장·조작·기존 원화·서사·난도 규칙은 보존했다. 저장/백업 회귀는 전체 자동 검사에 포함하지만, 이번에 실제 브라우저 다중 탭 저장 매트릭스나 사람의 전체 여정을 새로 완주했다고 표시하지 않는다.

일반 브라우저 캡처의 공유 파일 전달은 실패했다. 캡처 픽셀 자체는 확인했고, 같은 실제 캔버스는 페이지의 표준 PNG/JSON 내보내기로 정상 다운로드했다. 따라서 증빙은 실제 Chrome 캔버스 출력으로 표기하며, 존재하지 않는 스크린샷 경로를 제공하지 않는다. 검수 GIF20프레임은 CPU 면역 장면이다.
