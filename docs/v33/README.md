# v33 — 난사 레이저를 맵 끝까지 연결

기준: `1001693e009e3bc4d1dbd1ad9b859ad5936dedf7`(배포된 v32).

현재 전투 규칙31의 앞으로 생성되는 보스 난사 레이저는 실제 화면 경계 **x=0/360, y=0/640**까지 도달한다. `cross/reticle/relay/stairs/bars/fork` 등의 중간 끝점과 회피 통로 앞 길이 자르기가 원인이었다.

`src/boss-lasers-v28.js`는 `fullLength` 옵션에서 각 광선을 화면 경계까지 연장한다. 회피 통로에 닿으면 예고 전에 정해진 작은 각도 후보를 순서대로 검사해, 끝까지 이어지면서 통로를 침범하지 않는 경로를 선택한다. 불가능한 묶음은 예고 전에 제외한다. 반사 광선은 첫 구간을 실제 옆 벽까지 보내고 반사 방향의 다음 구간도 다음 경계까지 계산한다. 둘 중 하나만 생기거나 중간에서 잘리지 않는다.

`src/core.js`의 보스 난사 생성 호출에 현재 규칙31용 옵션을 연결했다. **예고선·피해 캡슐·잔광이 같은 끝점**을 사용한다. 발사 뒤 각도를 바꾸거나 플레이어를 추적하지 않는다. 이미 예고된 광선과 저장된 기존 광선은 약속한 경로를 마칠 때까지 유지하며, 다음 생성부터 새 정책을 적용한다. 이전 전투 규칙의 패턴 생성은 보존한다. 피해량·폭·시계·레이저 수 상한·원본 이미지·서사·저장 형식은 바꾸지 않는다.

앱 표시/캐시 버전은33(`20261101-fullbeam33`), 저장/전투 규칙은31이다. 새로고침하면 기존 규칙31 이어하기에도 다음 난사부터 적용된다.
