# v34 — 탄막이 배경에서 분리되어 읽히는 전투 화면

대상: `hapil-reboot`. 기준: 배포된 v33 `fb90bfb8c5bf9f63f7789b2c38fefc10927562ed`.

동방풍의 촘촘한 탄열과 저속 틈 읽기가 느껴지도록, 합일의 기존 보스·고유탄을 유지하면서 화면 명암과 겹침을 조정했다. 동방 캐릭터·탄환 이미지·음원·패턴 좌표를 가져오지 않았다. [동방풍신록 공식 Steam 설명/조작법](https://store.steampowered.com/app/1100140/)을 참고했으며, 낮춘 배경과 선명한 위험 요소의 조합은 본 프로젝트에 맞춘 시각 설계 판단이다. 영야초 공식 옛 페이지는 조회 도구에서 접근할 수 없었다.

## 실행본 변경

- `src/projectiles.js`: 현재 전투 규칙31의 레이저만 기존 source RGB를 재가공한다. 넓고 밝은 색 면이 판처럼 보이던 어깨를 낮추고, 좁은 밝은 중심과 원래 재질의 차이를 보강했다. 기존 알파를 그대로 유지하므로 피해 영역이 투명해지거나 구멍이 생기지 않는다. 색이 너무 낮아지지 않도록 기존 색상 비율을 유지한 최소 밝기도 둔다. 소유자별 색 우선순위와 이름·원화 재질을 유지한다.
- `src/render.js`: 전투 배경 아래쪽을 더 눌러 주는 정적인 잉크색 그라데이션을 추가했다. 현재 규칙31의 보스 전투에만 적용하고 첫0.6초에 부드럽게 들어온다. 보스·일반탄·플레이어 위를 덮지 않는다. HUD는 같은 상단 영역·한글 정보를 유지하면서 아래쪽이 부드러워지는 그라데이션으로 바꿨다.
- 분신이 할 일을 마친 후 갑자기 삭제되어 보이지 않도록 마지막18틱(0.3초)에 떠나는 모습을 페이드한다. 아직 예고한 발사가 있거나 실제 발사 후6틱 안이면 발사원은 선명하게 유지한다. 분신의 위치·수명·개수·실제 공격은 변경하지 않는다.
- 앱 표시 버전34, 캐시 `20261101-danmaku34`. 전투/저장 규칙31은 유지하므로 새 게임이나 저장 초기화가 필요 없다. v33의 맵 경계까지 이어지는 난사 레이저도 그대로다.

새 필터·블러·그림자·입자·다운로드할 비트맵 자산을 추가하지 않았다. 레이저는 기존 캐시와4MiB/96개 상한을 사용한다. 배경/HUD 그라데이션은 렌더러 생성 시 한 번 만들고 재사용한다. 분신 페이드는 기존 source draw의 알파만 바꾼다.

## 화면 검수와 검증

- [6보스 전후 장면](danmaku-before-after.png), [좌표·자원 기록](scene-review.json): 보라검천사·루시퍼·질투·색욕·교만·한리안/백이온의 실제 동일 코어 상태를 전후 렌더링. HELL31, 페이즈3, seed813, tick300. 명시적 무적·자동 공격/스킬 끔. **네이티브 Canvas 비교이며 자연 클리어 또는 휴대폰 FPS 기록이 아니다.**
- 절전/고품질12장면에서 모든 실제 광선과 분신을 유지했다. 자산 누락0, 워밍 후 새 캔버스 할당0, source 캐시 바이트는 기존 동일 장면과 일치한다. 이미지의 변화량은 품질 점수로 해석하지 않는다. 직접 검수로 광선의 평평한 밝은 면과 배경의 경쟁이 줄었음을 확인했다.
- `tests/danmaku-presentation-v34.test.cjs`:48개 레이저 조합에서 전후 알파 전 픽셀 동일성, 이전30 RGB 동일성, 현재31 source 일반탄의 RGB·모양·기준점·회전 동일성, 기존 장면 유지·캐시·세계 불변, 분신의 종료/예고/발사 가독성을 검사한다.
- [원본·전투·저장·서사 보존](preservation.json): 보호 파일305개가 기준 커밋과 동일하다. 탄속·개수·궤적·판정·피해·보스 페이즈·원본 이미지·음원은 편집하지 않았다.
- 실제 브라우저의 색욕·교만 고정 장면은 `tools/danmaku-review-v34.html`로 재현한다. 검수 페이지는 본편 로더에 넣지 않으며 저장 데이터에 접근하지 않는다.

실기기 모바일의 지속 FPS/GPU 시간과 자연 조작 전체 클리어는 이번 시각 검수로 확인하지 않았다. 캐시와 캔버스 재사용 결과를 실제 기기 성능 향상으로 주장하지 않는다.
