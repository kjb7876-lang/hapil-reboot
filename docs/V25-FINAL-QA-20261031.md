# V25 보스별 서사 전투 개선 검증

색욕 v24를 유지하고 나머지34개 전투 구성에 고유 압박 탄막 안무와 단계·시전자별 시전 연출을 적용했다. 기존 본편 공격,35개 정본 전투 정의, 보호 대상과 합일 코어를 남기는 몽세수호자 결말을 보존했다. 새 게임·연습은25, 기존 미지정·21 저장은 당시 규칙으로 이어진다.

나태는 지연·정지·재가속 휴지, 탐식은 아래 방향 식칼과 입 파동, 탐욕의 성인 단계는 지폐·금고상자를 사용한다. 소년의 기억 단계에는 새 돈·상자를 적용하지 않는다. 통제체계는 반복 연결의 개폐·분기, 한리안과 백이온은 역십자·방벽, 최종 교주는 Fold·Stitch·Impact 단계로 구분한다. 원본5종×4자세는 보존했으며 연속 애니메이션을 새로 제작했다고 주장하지 않는다.

전체장면 동기 CPU 측정은 고품질42/절전42장면이며 최대p95가 각각3.960ms/4.474ms였다. 최대 탄환 캐시는2750192B로4MiB 이내, warm miss0이다. 공유 CPU의 정지 장면 측정이며 휴대폰FPS나 GPU 완료 시간은 아니다. 실제 브라우저는 도구 동작 사이 약1017ms 프레임 공백에서 기존 안전 일시정지가 작동했다.

새 whole-object는 실제 판정 전체 가시성90% 기준을 유지했다. 기존 가늘고 긴 fitted 탄환3936사례는90% 미만인 잔여 한계가 있으며, v24 대비 악화0을 별도로 확인했다. 전체 탄환이90%를 덮는다는 의미가 아니다. 모든 중심 alpha80%와 과거 밝기 기준은 유지했다. 밝은 pivot의 판정72.73% 실패, 루시퍼 색 보정 회귀, 발록의 필수/선택 로딩 중복을 수정하고 최초 실패 로그도 보존했다.

root가 원본4종·파생물, 개별 자산4페이지, 전체 전투6페이지와 선택한360px 비교5개, 실제 Chrome 화면을 직접 확인했다. before/after 전투 사진은 동일한 후보 world에 이전/현재 렌더러를 적용한 비교다. 실제 브라우저 내보내기 파일은 동기화되지 않아 깨진 첨부 링크를 제공하지 않으며, 직접 관측한 UI 상태를 별도 JSON으로 기록했다.

제품13파일은 최종 검사 전후 SHA-256이 동일하다.295기존 이미지와284기존 별칭을 보존했고, 검증한4개 파생 자산183104B만 추가했다. 큰 원본 QA JSON2개는 옆의 gzip 파일로 바이트 그대로 보존하며 복원 명령과 양쪽 해시는 `V25-INDEPENDENT-RAW-ARCHIVE-20261031.json`에 있다.

배포 실행·공개 주소의 증거는 GitHub Pages 실행 후 별도로 생성한다. 상세 수치·소스 해시·한계는 같은 이름의 JSON과 각 담당 검증 보고서에 기록했다.
