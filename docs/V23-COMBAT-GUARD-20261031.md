# v23 전투·저장·자산 원본 보존 검수

배포된 v22 커밋 `c6c3febf736d8f45ea1ba955a78dc20c8b4e9a8c`과 실제 바이트를 대조했다. 코어·저장·조작·스토리/무기 계약 및 미디어 원본을 포함한 **302개 파일**이 동일하다. 런타임 변경 파일: `src/app.js`, `src/projectiles.js`.

`app.js`는 진단 버전 문자열만, `index.html`은 캐시 질의만 바뀌었음을 별도로 정규화해 확인했다. 원본 미디어/오디오의 새 생성·변환은 없다. 각 파일 SHA-256은 대응 JSON에 기록했다.

공유 색 조정 함수의 레이저 전용 분기가 일반 탄환을 바꾸지 않는지도 별도로 확인했다. 36개 자산 구성과 분리된 참가자 원본, 두 품질, 구형/칼날형의 **148개 실제 CPU RGBA 비교**가 배포된 v22와 바이트 단위로 동일했다. 같은 소스/팔레트의 레이저 캐시 사용을 끼워 넣은 뒤에도 동일했다.

이 검사는 전투 시뮬레이션 규칙 및 원본 보존 확인이다. 새 레이저 픽셀·클리핑·예고/발사/잔광은 별도 v23 검사로 확인해야 한다. 과거 113개 자연 입력 기록을 새로 재생했다고 주장하지 않으며, 이번 결과를 실제 브라우저 입력·GPU 완료 시간·휴대폰 FPS 통과로 분류하지 않는다.
