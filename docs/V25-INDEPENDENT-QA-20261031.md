## 픽셀과 형상

실제로 생성된1065경로를 양품질과4각도에서 그린8520사례를 검사했다. 픽셀 중심의 alpha180 가시성은 최저83.33%이다. 새 whole-object2368사례의 fullDamage alpha128 가시성은 최저93.75%이며, 단일 자산 draw와 소스 내부 명암·색상 세부를 확인했다. 256×256 격리 화면의 가장자리는 투명하므로 검수 화면의 잘림으로 통과한 사례가 없다.

큰 소품의 장식 끝은 기존 충돌 원·캡슐 밖에서는 피해를 주지 않는다. 소스 원화를 회전·준비·반동으로 연결한 표현이며, 정지 원화나 기존4자세를 새로 완성한 연속 애니메이션이라고 주장하지 않는다.

기존 fitted 탄환 중 fullDamage 가시성90% 미만인3936사례는 v24와 같은 기준으로 따로 대조했다. 악화는0이며, 가장 낮은 기존 사례는 G19 needle의32.14%이다. 이 잔여 한계를 전체 탄환의90% 가시성 통과로 표현하지 않는다. 새 whole-object의90% 기준과 기존 fitted의 가시성 회귀 방지는 서로 다른 검사다. 핵심 충돌 중심의80% 기준은 모든 사례에 유지했다.

과거 중심 구멍이 있던4종에 대해서는3각도×3subpixel×2palette×2품질의144사례를 추가 검사했다. 중심100%, 밝은 중심(alpha180/luma50) 최저83.33%, 과거 기준 대비 평균 밝기 최저91.57%, 실제 원·캡슐 전체 가시성 최저95.45%이다. ChronoShard와 IonShield에는 소스 내부 색상 노출 보정이 있으며, 모든 소스가 원본 RGB 그대로라고 주장하지 않는다. 보정은 기존 alpha와 충돌 형상을 바꾸지 않는다.

새 whole-object의9회전각×3subpixel×양품질4374사례는 중심100%, fullDamage 최저93.75%로 통과했다. 실제 경고·방출 source cue1260프레임에서 모든 예정 origin이 양품질 모두 표시되고 실제 방출 기록과 일치했다.

## 최초 실패와 수정

- 독립 교주 fixture가 revision5를 사용해 제품의 기존 revision3 전용 계약에서 중단됐다. fixture를 실제 앱 계약으로 고쳤고, 첫 오류 로그를 남겼다.
- VM 배열과 Node 배열의 prototype 비교, 내부 checkpoint의 선택 버전 필드 정규화를 바로잡았다. 첫 일반 체력105기록과 재기록의 결과·입력 gzip SHA는 전부 같다.
- 신경관문은 첫 잠긴 탈출로가 신규 보조탄 전체를 필터링해 첫 방출이751틱이다. 관찰을600에서840틱으로 늘려 두 번째 주기까지 확인했고, 경고·탈출로·누락 기준을 낮추지 않았다.
- 새 밝은 pivot이 실제 탄환 몸체를72.73%만 덮는 실패를 재현했다. 원래 안전한 pivot과96픽셀 소스 샘플링을 복원하고 소스 노출을 조정한 뒤144확대검사를 다시 통과했다. 최초 실패 JSON·로그·이미지를 남겼다.
- 픽셀 검수 중 제품이 바뀐80dd 후보 실행은 중단하고 source hash guard 실패로 기록했다. 최종 검수는2c831a71 후보에 맞춘 고정 스냅샷과 직접 해시 대조를 사용한다.

## 재현

`node tools/audit-boss-identities-v25.cjs --full`은 실제 core 관찰부터 새로 생성한다. 현재 릴리스의 저장된 core 관찰 스냅샷이 있는 경우 `node tools/review-boss-identities-v25.cjs /절대경로/v25-collected-worlds.json`으로 소스·장면 검사를 재개할 수 있다. `--resume-pixels`는 제품 해시가 완전히 같은8520픽셀 결과만 다시 사용하며, 접촉 시트 픽셀도 저장된 RGBA 해시와 대조한다.

일반 체력 재현 명령과 모든 기록·입력·재생 SHA는 `V25-NATURAL-HEALTH-FOLLOWUP-20261031.json`에 있다. 저장·다중 탭은 저장 담당 검증 문서, 실제 브라우저와 배포는 최종 릴리스 검증 문서에서 별도로 확인한다.

큰 raw JSON2개는 검사 후 byte-exact gzip(mtime0)으로 저장했다. 원문은 실행 환경에 유지하고 Git에는 `v25-qa/actual-source-pixels.json.gz`와 `v25-qa/actual-emitted-routes.json.gz`를 저장한다. 압축·원문 해시와 복원 명령은 `V25-INDEPENDENT-RAW-ARCHIVE-20261031.json`에 있으며, 최종 JSON은 이 보관 경로와 decoded 원문 SHA를 참조한다. 저장 형식 변경은 검사·기준·입력·소스 해시를 변경하지 않는다.
