# v22 분신 반복 시전 자세 검수

실제 v21 코어에서 분신의 첫 발사는 준비 자세를 보여 주지만, 반복 발사는 회복 자세에서 발사 자세로 바로 바뀌었다. 보라검천사 헬·세 번째 패턴·seed813의 첫 분신은151틱 생성,193틱 첫 발사,253틱 재발사다. 기존252틱은 `recover`였다.

렌더링용 임시 배우만 조정해 반복 발사 전18틱에 이미 있는 자기 원화 준비 자세를 표시한다. 생성 틱·안정적인 분신 번호·실제 난도별60/90/120틱 주기로 다음 시점을 읽으며, 원래 코어 객체·조준·탄환·저장·RNG는 바꾸지 않는다. 실제 발사 표식이 우선하고, 만료 직전 발사 제한 이후에는 준비 자세를 만들지 않는다. 같은 분신의 지연 발사가 대기 중이거나 탄환 용량이 가득 차면 예측 준비 자세를 생략한다.

추가로, 같은 분신의 마지막 예정493틱은 코어가 의도적으로 발사하지 않지만 명목상 `attack` 상태는 남는 문제를 확인했다. 실제 마지막 발사는433틱이므로502틱에 공격 자세를 표시하던 부분을 로컬 회복 자세로 바꿨다. 최근 실제 발사21틱은 원래 자세를 유지한다. 분신은 원래511틱에 사라진다.

새 전용4검사와 기존 분신5검사, 합계9개가 통과했다. 전체 회귀 검사는 부모 담당이며 이 결과를 전체 게임 검증으로 부르지 않는다. 자기 원화37개를 로딩해 실제 코어6사례의 배포본/수정본 이미지를 만들고 직접 픽셀을 확인했다. 한리안·백이온처럼 준비 전용 원화가 없는 몸체는 자기 정지 자세를 유지하며 새 애니메이션이라고 주장하지 않는다.

정확한 원본·소스·제작 결과 해시는 JSON과 `docs/v22-copy-pixels/repeat-source-before-after.jpg`에 기록했다. CPU 고정 면역 관찰이며, 자연 진행·사람 반응·GPU·휴대폰 성능 인증과 구분한다.
