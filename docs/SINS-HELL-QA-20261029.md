## 검사 종류와 한계

2026-10-29 최종 QA 실행 시점의 `npm test` 결과는 **151 통과 / 0 실패 / 0 생략**이었다. 기존 저장·백업·실패 지연·다른 클라이언트의 오래된 쓰기 거부 검사는 순수 reducer 또는 모의 저장 계층 검사다. 실제 브라우저 여러 탭의 IndexedDB 시험으로 분류하지 않는다.

실제 PNG 19개(인물·후속형 9개, 탄환 소재 7개, 분노의 귀 정적 형상 3개)의 파일 해시·크기·디코딩을 검사했다. 인물 36자세의 수동 몸통 부착점은 실제 불투명 픽셀 안에 있었으며 네 자세마다 자신의 원화만 그렸다. 손상·누락된 원화는 플레이 전에 거부했다. 탄환 소재의 실제 원형 내부 알파 최솟값은 원본 기록과 같은 250~253이었고 도형 배경을 덧그리지 않았다. 사각형 크롭의 모서리는 실제 위험 영역 바깥이므로 원형 내부와 구분했다. 새 일곱 소재는 개별 비행 애니메이션으로 주장하지 않는다.

CPU 전체 렌더러에서 12전투 모두 두 품질 설정으로 탄환 768개와 활성 위험선 40개를 그리는 검사를 확장했다. 이는 관찰된 자연 진행 밀도가 아니라 강제 상한 fixture다. 분노의 귀의 곰·늑대·용은 각 페이즈 예고와 실제 공격 직후에 나타나는 정적 형상이며 플레이어 통로 위에만 그려지고 별도 피해 판정은 없다. 기존 다섯 보스와 새 일곱 보스의 몸 주변에 렌더러가 흰 원을 추가하지 않는 검사도 통과했다. 몸통 부착점은 시각 등록이며 원본의 물리 피벗 인증을 뜻하지 않는다.
