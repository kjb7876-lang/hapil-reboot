# v22 독립 예고 픽셀 검증

v21의 넓은 레이저 예고는 전체 폭에13% 색을 깔지만, 강한 점선과 명암은 중앙선에만 있었다. 특히 가로·격자 광선에서 실제 피해 범위의 바깥 경계를 읽기 어려웠다. 이번 검사는 엔진이 실제로 예고한 좌표·폭을 그대로 사용하고, 같은 상태에서 대상 예고 하나만 뺀 화면과의 픽셀 차이로 이를 확인했다. 화면용 가상 공격 좌표를 새로 만들지 않았다.

최종8구성×3난도×상·하 품질 **48사례**에서 세로·가로·격자 범위를 검사했다. 현재와 배포v21 각각 대상 포함/제외로 총192회 전체 렌더를 비교했다. 고정 관찰을 위해 플레이어 외부 면역을 설정하고 자동 공격·스킬을 껐다. 자연 진행, 실제 사람, 브라우저, GPU, 휴대폰 FPS 검사가 아니다.

독립 기준은 실제 경계의0.7~2.6px 안쪽, 다른 공격/플레이어/탄환에 가리지 않은 픽셀의 최대RGB 변화40 이상인 비율이다. 13% 단색 예고만으로는8비트 각 채널이 최대34까지만 바뀌므로40은 희미한 면과 새 경계선을 구분한다. 약2px 경계 띠 안의 최소45%를 기준으로 삼았다. 이 수치는 위험 면적이나 인간 지각의 보증을 뜻하지 않는다.

| 검사 | 최종 결과 |
|---|---|
| 실제 위협 외곽의 강한 경계 비율 | 모든48사례 통과, 최소49.84%; 동일 기준의 v21 대조군0% |
| 실제 범위 밖의 오해 유발 표시 | 실제 캡슐+1.1px 안티앨리어싱 허용 폭 바깥 변화0픽셀 |
| 어두운 타락천사 기사 | 첫.9px 시안은25.78%로 실패. 기준을 유지하고 자기 색 경계선을1.4px로 조정한 뒤65.79% 통과 |
| 경고→피해→잔광 | 실제 경고 마지막 틱에만 외곽선 존재; 활성·잔광 때 경고선 재등장 없음 |
| 입력 상태 보존 | 각 렌더 전후 실제 코어 상태 일치 |
| 원화 로딩 | 검사 시 자산 누락0 |
| 소스 고정 | 최종13개 제품 파일 해시 전후 일치 |
| 별도 회귀 | 실제3형상/3난도와 어두운 기사, 실제 활성/잔광 경계 검사2개 통과(실패·생략0) |

전후 합성 이미지의8개 실제 헬 장면을 직접 확인했다. 어두운 돌계단과 밝은 금빛 배경에서도 실제 경계를 읽을 수 있고, 경계선이 다른 새 피해 영역처럼 바깥으로 번지지 않았다. 원화와 탄환·레이저 본체는 바꾸지 않았으며, 자기 색을 사용하는 경고선의 표시만 강화했다. 한리안·백이온 시전자별 경고 색의 전달 문제는 표시 담당자의 별도 실제 시전자 회귀 검사로 확인한다. 이 문서의48사례 픽셀 검사와 구분한다.

첫 실패는 `v22-qa/warning-edge-first-failure.log`로 보존했다. 자동 검사 도중 발견한 VM 객체 프로토타입 비교 문제는 JSON 내용 비교로 수정했으며, 픽셀·전투 기준을 완화하지 않았다. 최종 상세 좌표·팔레트·소스 해시·픽셀 통계는 `V22-WARNING-PIXEL-REVIEW-20261030.json`, 재현 도구는 `tools/audit-warning-footprints-v22.cjs`, 회귀는 `tests/independent-warning-pixels-v22.test.cjs`다. CPU의 한글 폰트나 실제 휴대폰 성능을 인증하지 않는다.
