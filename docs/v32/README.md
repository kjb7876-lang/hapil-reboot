# 세로 합일 v32 — 전투 이펙트와 렌더링 비용 개선

대상은 `kjb7876-lang/hapil-reboot`이다. 기준 main은 `86f45afa49b282cfb20c03263904e576bc1b89f8`(v31), 작업 브랜치는 `claude/v32-portrait-fx`다. 잘못 만든 스토리월드 m0 PR #120은 사용자 지시에 따라 **미병합 상태에서 닫아 철회**했다. m0의 다른 작업이나 main은 되돌리지 않았다.

## 실제 실행 경로

- `src/projectiles.js`: 같은 탄환의 이미지·반지름·길이·팔레트가 같으면 이전 스탬프 연결을 재사용한다. 매 프레임 긴 캐시 키 문자열을 만들 필요가 없다. 코어가 탄환 객체를 재사용하거나 크기/팔레트를 바꿀 때는 다시 선택한다. 4MiB/96개 기존 캐시에서 쫓겨난 이미지는 재사용하지 않는다. WeakMap이라 사라진 탄환을 계속 붙잡지 않는다.
- `src/render.js`: 현재 전투 규칙31에서 완전히 화면 밖에 있는 탄환만 그리기를 생략한다. 회전된 전체 이미지, 기준점, 필터 여유와 보조 무기 이미지까지 포함하는 보수적인 범위를 사용한다. 탄환 배열·궤적·시간·피해는 건드리지 않으며 다시 들어오면 현재 프레임으로 그린다. 이전 전투 규칙의 제출 경로는 유지한다.
- 피격/처치의 단순 원·십자 표시를 기존 `fxResonance`/`fxSlash`의 네 프레임으로 보강했다. 피격은 원본 알파와 밝기 세부를 유지한 검붉은/자주색, 처치는 원래 금빛이다. 실제 효과 수명 전체를 사용하고 마지막 30%를 페이드한다. 추가 피해·입자·흔들림·블러는 없다.
- 피격 확인은 프레임당 최대2개, 처치 장식은 절전6개/고품질10개로 제한한다. 피격 예산은 별도이므로 처치 장식이 많아도 피격 확인을 밀어내지 않는다. 추가 캐시는 최대663,552바이트(648KiB), 종료 시 해제한다. 이 예산은 장식에만 적용되며 적 탄환/레이저에는 적용하지 않는다.
- `index.html`의 모든 캐시 키를 `20261101-portrait32`로 맞췄고 앱 진단의 표시 버전은32다. **전투/저장 규칙은31을 유지**한다. 기존 이어하기를 마이그레이션하거나 초기화하지 않는다.

색욕의 하이힐·립스틱·깨진 하트, 질투 반사, 교만 건반, 루시퍼 성좌 등 기존 v27~31 보스 구분·긴 레이저 연사·최대4체 분신·보스 잡몹 제거·아군 스킬 감속은 보존한다. 이번 변경이 새 패턴35종을 다시 만든 것은 아니다. 코스믹 루시퍼의 원래 얼굴 복원도 유지한다.

## 한계

메인 페이지의 자산 로딩·색욕 특수 연습 진입·설정 전환은 브라우저에서 확인했다. 실시간 모드는 긴 프레임 간격으로 자동 일시정지가 반복되어 지속 플레이/FPS를 검증하지 못했다. 해당 관찰만으로 원인을 단정하지 않는다. 고정 장면 검수는 성공했으나 **실기기 모바일30FPS, GPU 메모리/시간, 브라우저 GC 빈도, 오디오 지연은 미검증**이다. 공유 CPU 타이밍 변동을 숨기지 않고 모든 표본 결과를 기록한다.

검사용 HTML은 `tools/portrait-review-v32.html`에 별도로 있으며 게임 로더에 연결하지 않는다. 제품 수정은 기존 `index.html → src/app.js → render/projectiles` 경로에 연결되어 있다. main 병합·공개 배포는 하지 않는다.

재현: `npm test`, `node tools/review-portrait-v32.cjs`, `node tools/review-impact-v32.cjs`. 네이티브 픽셀 검사는 기존 `@napi-rs/canvas` 0.1.100과 기준 커밋 객체가 필요하다.
