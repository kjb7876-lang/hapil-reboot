# 7대죄 · 헬 모드 배포 후보

기준 main은 `1f42fa8d78f379c531dccc74f2bc919a78ec1aa0`이며 기존 저장소의 세로 게임을 확장한다. `hapil1`과 `m0`는 수정하지 않았다. 이번 범위는 기존 5보스부터 제2부 7대죄와 같은 회장의 생체 부트로더 후속전까지다. 제3~8부 전체와 최종 결말까지 완료했다는 뜻은 아니다.

## 플레이 변경

- 정본 순서: 나태 벨페고르, 질투 레비아탄, 탐식 베엘제붑, 색욕 아스모데우스, 탐욕 맘몬, 분노의 귀, 교만의 회장. 맘몬의 소년 기억과 회장의 사이보그는 같은 인물의 마지막 페이즈이며, 교만의 회장은 기존 루시퍼와 다르다.
- 신규 7종은 각자 세 페이즈와 고유 탄막 구성을 가진다. 바는 사람의 생명이 아닌 `봉인 저항`으로 표시한다. 신체에 확인되지 않은 새 손무기는 추가하지 않는다.
- 새 여정은 보스마다 최소 약 45초의 일반 전투를 진행한 뒤 조우한다. 보스 연습은 해당 전투에서 시작한다. 오래된 rev1/rev2 저장은 3명/5명 종료 지점과 기존 진행 시간을 유지한다.
- HELL은 별도 난이도 선택이다. 동일 시드에서 재현되는 제한된 탄속 변화, 짧은 공격 주기와 예고 후 연속 공격을 사용한다. 예고 시간을 제거하거나 탄환 상한을 늘리지 않았다.
- 적·보스 주변에 코드로 그리던 장식 원을 제거했다. 플레이어 피격점, 실제 탄환, 레이저 예고는 보존했다.

## 참고와 자산

동방의 탄막 회피, 컵헤드의 보스 중심 전투, 텐가이의 슈팅 리듬을 설계 방향으로 참고했다. 이번 구체적인 탄막은 해당 게임에서 복제했다고 주장하지 않는 독자적인 구성이다. 참고한 공식 소개: [동방](https://touhou-project.news/titles/th19/), [Studio MDHR](https://studiomdhr.com/press-kits/), [PSIKYO PORTAL](https://psikyo-portal.com/).

Drive의 StoryWorld/합일 자산 총색인과 관련 묶음을 대조해 실제 역할에 맞는 9개 몸체 원화와 4개 공격 소재를 사용했다. 모든 Drive 파일을 전부 다운로드하거나 모두 사용했다는 뜻은 아니다. 없는 후반 3종 탄환과 분노의 곰·늑대·용 정적 공격 형상은 내장 이미지 생성 도구로 제작했다. 외부 유료 API를 사용하지 않았다. 출처·정확한 프롬프트·SHA-256·Drive 업로드 메타데이터는 아래 기록을 따른다.

- `SINS-ASSET-SOURCES-20261029.json`: 최신 원문과 원화·매니페스트 대조
- `SINS-PROJECTILE-SOURCES-20261029.json`: 자신의 원화에서 가져온 재질, 보스 색과 알파
- `SINS-GENERATED-ASSETS-20261029.json`, `SINS-DRIVE-UPLOADS-20261029.json`: 신규 정적 PNG 6종과 업로드 확인
- `SINS-DISPLAY-CONTRACTS-20261029.json`: 수동 가슴 기준점, 배율과 표시 계약

네 개의 독립 자세는 연속 애니메이션이 아니며 물리 피벗 인증도 아니다. 분노 형상은 상단에 나타나는 정적 공격 표현이다. 새 구간의 배경은 기존 돌바닥 일부를 재사용한 추상 기억 무대다. 호텔·주방·금고 전용 지도, 회장의 뇌/화면 전체 연출을 완료했다고 표시하지 않는다.

## 검증

전체 Node 검사 151개 통과, 실패·생략 없음. 일반 체력·보통 입력을 사용하는 자연 진행 봇은 NORMAL/GENTLE/HELL 각각 두 시드, 총 6회 모두 12보스·36페이즈를 완료했다. 각 실행의 새 체크포인트 69개를 복원하고 최대 180틱을 비교했다. 상세 조건과 결과는 `SINS-HELL-QA-20261029.md`를 따른다. 긴 탄막 관찰에 사용하는 별도의 무적 fixture는 자연 진행과 구분한다.

CPU Canvas 측정은 실제 이미지 57개와 2,040개의 정지 화면 그리기로 수행했다. 모든 전투에서 누락 자산은 0이었으며 관측된 탄환 최대는 129개였다. GPU 완료 시간, 장시간 실제 브라우저 성능, 네트워크·첫 디코딩 비용과 실제 모바일 기기를 측정한 결과가 아니다. 상세 수치는 `SINS-HELL-CPU-20261029.json`을 따른다.

## 실제 Chrome에서 확인한 범위

로컬 후보 게임에서 HELL을 선택하고 교만의 회장 연습을 시작했다. 새로 고친 다른 375×812 문서 뷰포트에서도 선택한 HELL이 유지되고 메뉴·이동 패드가 화면 안에 배치되는 것을 확인했다. 이는 iframe 배치 확인이며 모바일 장치나 터치 하드웨어 에뮬레이션이 아니다. Cloud 브라우저가 도구 호출 사이 긴 프레임 공백을 만들 때 게임의 기존 자동 일시정지가 작동했으므로 사람의 연속 완주나 모바일 프레임 보장은 하지 않는다.

별도 관찰 화면은 실제 엔진·렌더러·이미지 32개를 사용한다. 일반 체력으로 페이즈 시작 체크포인트를 선택하고 자동 공격·스킬만 끈 fixture다. 새 7종 모두 100틱에 예고선이 보였고, 두 번째 페이즈의 169틱에 각각 2/2/4/3/3/3/3개의 광선이 활성화됐다. 같은 위치에 선 플레이어의 체력이 실제 활성선에서 줄었다. HELL 세 번째 페이즈 260틱에서 탄환은 각각 71/40/113/17/22/51/20개, 자산 누락 0개였고 맘몬 소년·회장 사이보그는 자신의 원화를 사용했다. 이 검수 화면의 페이즈 선택은 자연 진행으로 표시하지 않는다.

실제 IndexedDB 두 탭 검사는 게임 DB와 분리된 테스트 DB에서 현재 storage 모듈의 DB 이름만 바꿔 수행했다. A의 첫 HELL 저장(revision1) 후 B의 오래된 설정/진행 쓰기를 거부했다. B는 읽기만 하는 peek로 쓰기 권한을 얻지 못했다. 명시적 load 이후 B가 bossIndex11/phase2를 저장(revision2)하자 A의 오래된 패배 기록을 거부했으며, checkpoint serial2와 backup serial1이 보존됐다. A가 최신 기록을 읽고 패배를 기록한 뒤 새 retry ID로 checkpoint/backup을 보존(revision3)하고 runs/completed는 각각 1이었다. B의 오래된 설정 쓰기는 다시 거부됐다.

로컬 미러에 없던 기존 대형 지도 7장과 이전 효과/음악은 검수에서 기존 공개 배포 자산 URL을 사용했다. 신규 자산은 로컬 후보 파일을 사용했다. 최종 공개 배포 확인은 GitHub Pages 작업 결과와 공개 주소에서 별도로 수행한다.
