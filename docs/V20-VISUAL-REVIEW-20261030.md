# V20 전투·연출 CPU 및 이미지 대조

현재 상태: 실제 source 이미지의 CPU 렌더·상태 대조와 아래 범위의 직접 픽셀 검수를 통과했다. 이 결과는 통제 fixture 범위에만 적용한다. 시간 측정은 최종 소스에서 한 번 실행했으며 추가로 반복하지 않았다.

## 검사 범위

| 구분 | 이번 실행 |
|---|---|
| 실제 source 이미지 | 제품의 구간별 선택 함수로 로딩한 원본; 경로·SHA-256·규격을 JSON에 기록 |
| phase3 고정 장면 | 36선택 × NORMAL/HELL × 예고/실제발사/밀집 최대 × 고/저품질 = 432 |
| 시간 측정 | HELL 216장면 × 20회 = 4320회. 장면별 4회 예열은 측정에서 제외 |
| 실제 전환의 잔탄 | 36선택 × NORMAL/HELL × 고/저품질 = 144장면. 별도 HP1·지연피해 fixture |
| v19/v20 동일 상태 비교 | 1·7·19·20·30·31·34·35의 실제 peak. 각 쌍은 정확히 같은 core tick과 상태 |
| 지속 FPS·실제 기기·GPU | 검증하지 않음 |

phase fixture는 제품 체크포인트 API로 세 번째 문양을 복원한 뒤 자동 공격과 스킬을 끄고 피해 면역을 설정한다. 전환 fixture는 두 번째 문양의 실제 탄환이 있는 상태에서 boss HP를 1로 낮추고 실제 지연 피해를 적용하여 엔진의 정상 전환 분기를 실행한다. 둘 다 자연 진행으로 세지 않는다. 자연 진행 검사는 별도 QA 문서를 참조한다.

## 측정과 안전 조건

CPU p95 범위는 0.61~8.04ms다. native CPU Canvas의 반복 그리기 시간으로 이미지 디코딩·시뮬레이션·브라우저·GPU 완료·휴대폰 FPS를 포함하지 않는다. 이전 버전의 다른 장면 집합이나 다른 측정 도구의 수치와 직접 속도비를 계산하지 않는다.

실제 레이저가 있는 65개 선택/난도에서는 동일한 committed capsule을 activeAt−1과 activeAt에 관찰했다. 원점·종점·폭·활성 틱이 같은지 비교했다. 레이저가 없는 경우는 JSON의 noLaserFallbacks에 실제 준비/탄환 발사 상태로 명시하며 레이저 검사로 세지 않는다.

현재 renderer는 실제 탄환 수와 texturedBullets가 같고, 누락 자산·상태 변조가 0이었다. HUD의 예고·활성 수와 남은 시간은 원래 엔진 상태와 같았다. 전환의 살아 있는 탄막은 residual-danger로 표시하고 안전한 클리어로 바꾸지 않았다. 지속 HUD의 아래 경계는 y64 이하다. 반복 그리기에서 배경·문자 배치를 새로 만들지 않았다.

탄환 캐시 4MiB, 스킬 캐시 2MiB, 장면 1,036,800B, 검격 캐시 24,576B 상한을 확인했다. core/storage/미디어/무기 엔진은 기준 v19와 같은 바이트다. 스토리 자산 표는 g31 blade anchor x288→288.5와 한리안 blade fixedOrientation true→false의 표시 보정 두 값만 달라졌으며, 나머지 모든 소유자·원본·규격·내용은 같음을 비교했다. 전체 13개 생산 파일은 측정 전후 SHA-256이 같았다.

## 직접 픽셀 검수 세 차례

1. 동일 core 상태의 v19 기준 화면을 먼저 확인했다. 큰 중간 패널이 조밀한 탄막 영역을 가로지르고, 일부 자연 실루엣은 장면과 명도가 가까웠다.
2. 여덟 구성의 같은 틱·같은 상태인 v20 출력과 원래 360×640 표시 크기로 대조했다. 중간 패널이 없어졌고 검·피리·곡검·쌍 시전자의 고유 탄체 윤곽이 유지됐다. 한리안의 긴 역십자는 실제 이동 축을 따른다. 여섯 검격 발사 원점은 새 대표 위치 진단값과 별도 QA로 구분했다.
3. 최종 고정 소스의 전체36 선택을 예고·첫 활성·밀집 최대의 세 모음으로 직접 확인했다. 새 사각 카드나 이미지 누락, 중간 패널로 인한 탄막 가림 오류는 발견하지 못했다.144개 전환은 실제 렌더 상태값으로 잔탄 위험을 확인했으며, 모든 전환 픽셀을 개별 검수했다고 주장하지 않는다.

세 차례는 같은 고정 출력에 대한 서로 다른 대조·검수 단계다. 시간 측정이나 자연 진행을 세 번 실행했다는 뜻이 아니다. CPU의 한글 형태와 실제 Chrome 입력/실기기/GPU 검증은 포함하지 않는다.
