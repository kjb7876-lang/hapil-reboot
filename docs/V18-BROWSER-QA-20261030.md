- 실제 UI에서 기억의 문 연습(18)을 선택하여 정상 체력 3/3으로 시작했다. 첫 장면에서 다음 장면 자산을 먼저 로딩하고 전투를 여는 동작을 확인했다.
- 실제 방향키 입력으로 플레이어 x=180→216, 실제 화면 드래그 입력으로 216→245.5994494 이동, pointer capture 해제를 확인했다. 무적이나 777을 사용하지 않았다. 짧은 조작 스모크이며 자연 전체 클리어 증거가 아니다.

- 방어의 군단 연습(13) 실행 후 reload/이어하기에서 첫 탭의 같은 runId가 복원됐다. 본편 checkpoint와 backup JSON은 보관한 값과 동일했다. 복원은 일시정지로 시작했다. 손상 레코드 복구·지연/실패 주입은 자동 fixture 검사 범위이며 이 UI 검사와 혼동하지 않는다.
- 실제 렌더러를 쓰는 별도 검수 페이지에서 phase3 경계, 자동 공격/스킬 중지, 정상 체력의 관찰 fixture를 사용했다. seed813 HELL 기억의 문 tick100은 warning2/actual laser0/charge자세, tick151은 active2/실제자산레이저2/실제 releaseTick151과 release자세였다. 90틱 예고의 실제 피해 판정은 엔진 회귀 검사로 따로 확인한다. 이 고정 관찰은 자연 진행이 아니다.
