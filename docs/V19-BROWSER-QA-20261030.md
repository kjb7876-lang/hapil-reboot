## 고정 장면과 픽셀

`story-review19.html`은 실제 core의 phase2를 선택하고 자동 사격/스킬을 끈 뒤 피해 면역을 설정한 통제 fixture다. 1200틱 중 실제 예고·발사·중첩 최대 상태를 보존하여 실제 renderer로 표시한다. 자연 진행 또는 실제 브라우저 프레임 성능 검사로 세지 않는다.

새17구성(그룹19~35)의 실제 맵·주인공·상대·전용 스킬·탄환을 확인했다. 각 장면은 자신에게 필요한6~11개 이미지만 로딩하며 실제 탄환 수와 texturedBullets가 같고 missingProjectileAssets=0이었다. 보스별 특수 패턴 이름과 안내의 한글 픽셀도 Chrome에서 확인했다. CPU 환경에는 한글 폰트가 없어 CPU 이미지로 한글 가독성을 인증하지 않는다.
