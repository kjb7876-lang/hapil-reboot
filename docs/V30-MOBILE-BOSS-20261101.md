## 적용

- 보스 단계에서 지원 적의 생성 입구를 차단한다. 일반 구간 적, 보호 코어·장면 객체·서사는 유지한다.
- 추가 공격의72·168·342·420틱 슬롯을 실제 분신이 시전한다. 경고·탄 수·예약을 복제하지 않으며, 최대4체/360틱 수명과 실제 발사 위치·소유자 기록을 따른다. 보스의 기존 레이저 주인은 유지한다. 분신이 허용되지 않는 보호 장면은 그대로다.
- 모바일은 저장된 고품질 설정보다 절전 시작 설정을 우선한다. 화면 목표30Hz·DPR1이며 전투 계산60Hz는 유지한다. 수동 고품질 전환은60Hz 목표·DPR최대1.5로 정상 동작한다. 작은 뷰포트도 모바일 경로로 인식한다.
- 30 절전 렌더는 연속된 실제 활성 압박 광선이4개 이상인 묶음만 backing-store 해상도의 단일 원화 캐시에 합성한다. 캐시는 하나·최대4MiB이며, 기하·색·소유자·단계·화질·크기·원본 이미지가 바뀌면 무효화한다. 상한 초과·원화 누락은 직접 그리기 경로로 돌아간다. 고품질과 구형 규칙의 원시 픽셀은 유지한다. 캐시 합성의 작은 채널 반올림 차이는 별도로 검사한다.
- 모바일 배경 장식·프레임 그림자·블러 합성을 줄인다. 탄환·활성 광선 본체를 생략하지 않는다.
- 30의 수명 초과 이동 탄은 최대180개의 비감속 고정 틱 동안 원래 궤도를 유지한다. 그 뒤에도 남는 탄과 정지 탄은0.8초 무해한 페이드로 끝낸다. 최대 표시 범위를 고려한104px 이상의 이탈 여백을 사용한다. 기존 규칙의 수명·피해·저장 결과는 유지한다.

## 탄환 소멸 원인과 비용

큰 소품의 이탈 처리도 원인이었다.29 탐식·지옥 첫 페이즈2,400틱에서 정리된 큰 탄1,626개 중635개는 원화 일부가 아직 화면에 남아 있었다. 예시 칼날은 중심이 화면 밖으로 나갔어도210개의 픽셀이 남았다.30은 표시 범위를 포함하는 여백으로 이 꼬리 잘림을 방지한다.
