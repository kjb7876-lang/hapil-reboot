# v25 후보 코드에서 기존 일반 체력 입력 기록 재검증

기존 자연 진행 검사 3개 파일의 소스 해시 경계가 v25의 새로운 선택 규칙을 포함한 `core.js` 및 저장 보호를 포함한 `storage.js` 변경을 감지했다. 이전 입력 기록의 출처를 현재 해시로 덮어쓰지 않고, 기존 입력을 현재 후보에서 모두 재생한 별도 검증 기록을 만들었다.

원래의 세 `manifest.json`, 18개 `.moves.gz`, 입력 정책과 녹화 도구는 변경하지 않았다. 녹화 당시 해시와 이전 재검증 해시도 원문 그대로 남아 있다. 새 문서는 과거 녹화를 현재 후보에서 다시 검증했다는 뜻이다.

`tools/revalidate-historic-inputs-v25.cjs`는 새 입력을 만들거나 정책·녹화 도구를 실행하지 않는다. 원래 gzip 입력과 해시를 읽고 다음을 확인한 후에만 같은 이름의 JSON 증명서를 쓴다.

- 캠페인 규칙 3·4·5 각각 여유·노멀·헬 × 시드 813·42: 총 18개 입력을 처음부터 끝까지 그대로 재생한다.
- 기본 일반 체력·자동 공격·스킬을 유지한다. `777`, 외부 무적, 체력·피해·난수·시간·페이즈 변경을 하지 않는다.
- 입력 수, 최종 승리 시점, 체력, 피격, 점수, 처치, 체크포인트 수, 모든 페이즈 전투 시간과 모든 저장 경계 기록이 원래 결과와 일치한다.
- 실제 저장 검사기를 통과한 모든 경계에서 복원한 뒤, 원래 입력의 다음 최대 180틱을 현재 진행과 함께 재생한다. 충돌체·보스·탄환·레이저·자원·난수·타이머 등 전투 상태와 새로 생긴 이벤트를 매 틱 비교한다.
- 모든 원본 입력·매니페스트·정책·녹화 도구와 후보 소스의 검사 전후 해시를 확인한다.

18개 모두 통과했다. 원래 일반 체력 입력은 3,699,860틱이며, 검증한 저장 경계는 2,286개다. 복원 전후의 미래 입력 411,480쌍을 비교하여 추가로 822,960엔진 틱을 실행했다. 원본 보관 파일 수정 수는 0개다.

이 기록들은 원래 `combatRevision` 필드 없이 녹화된 입력이다. 재생에서도 이 필드가 없는 것을 명시적으로 확인한다. 새 v25 압박 안무에서 전체 스토리를 자연 진행으로 완주했다는 증거가 아니다. 실제 브라우저·사람 조작·GPU·휴대전화 FPS 검사도 아니다.

세 필수 테스트의 기존 진행·피해·저장·패턴·결말 단언은 보존했다. 앞부분의 소스 검사는 이제 `tools/historic-replay-attestation-v25.cjs`를 통해 다음을 함께 고정한다.

1. 원본 매니페스트와 입력 gzip의 SHA-256 및 원래 녹화 출처
2. 모든 원본 모듈·정책·녹화 도구 키를 보존한 현재 후보 소스 해시
3. 변경되지 않은 무기·정책·녹화 도구의 원래 해시
4. 18개 입력의 실제 재생 결과와 저장 경계 개수
5. 검증 로더 자신, 전체 재생 검증 도구, 세 테스트 파일의 SHA-256

그러므로 소스나 검사 단언을 변경하면 이 증명서를 그대로 재사용할 수 없다. 현재 후보에 대한 재생 검증을 다시 해야 한다. 해시 검사를 건너뛰는 환경 변수, 임시 매니페스트 변경이나 무조건 허용하는 경로는 추가하지 않았다.

독립 전체 재검증 로그는 `docs/v25-qa/historic-input-revalidation.log`, 이후 원래 세 필수 테스트의 실제 실행 로그는 `docs/v25-qa/historic-replay-mandatory-gates.log`에 보관한다.
